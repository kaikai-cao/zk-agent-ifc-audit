# Phase 1D — D2：最小有限状态 Agent 模型

证据标记：`[定义]`、`[数学推导]`、`[待验证]`。本文件只定义模型，不声称模型忠实描述任何真实 Agent。

---

## 1. 设计目标与边界

**目标**：定义一个足够承载"有界非干扰性"研究问题、又不把无限状态 LLM 当作已解决对象的最小模型。

**边界声明（必须先写）**：
> 我们证明的是**给定有限模型 M 的性质** `C_T(M)`。这**不**自动证明 M 忠实描述了某个真实 Agent 的执行；从真实执行到 M 的映射（抽象、采样、完整性）属于模型验证/信任边界，不在本证明关系内。这与 Phase 1C `SECURITY_MODEL.md` 的"采集器完整性未被 ZKP 消除"同构，只是上移到模型层。

---

## 2. 模型定义

```
M = (S, X_L, X_H, Init, δ, A_L, A_I, Obs_L, status, T)
```

### 2.1 状态集合 S

一个状态 `s ∈ S` 是六元组：

```
s = (pc, m_L, m_H, tool, buf, term)
```

| 分量 | 含义 | 敏感级别 |
| --- | --- | --- |
| `pc` | 控制位置（程序计数/阶段），有限集 `PC` | 可低可见或隐藏，按策略 |
| `m_L` | 低上下文内存，有限域 `M_L` | Low |
| `m_H` | 高敏感内存，有限域 `M_H` | **High（隐藏）** |
| `tool` | 工具调用状态：`idle` 或 `(t, args, pending)` | 参数可含 High |
| `buf` | 公开输出缓冲区，有限字母表 `O` 上的串（长度 ≤ T） | Low |
| `term` | 终止标志 ∈ `{RUN, DONE, STUCK}` | Low |

有限性：`PC, M_L, M_H, O, T, A_L, A_I` 全部有限 ⇒ `S` 有限。`|S| ≤ |PC|·|M_L|·|M_H|·|ToolState|·|O|^{≤T}·3`。

### 2.2 输入与初始化

```
x_L ∈ X_L : 低输入（公开上下文、公开问题、公开配置）
x_H ∈ X_H : 高输入（秘密文档、密钥、私密记忆）

Init(x_L, x_H) = (pc₀, x_L, x_H, idle, ε, RUN)
```

`x_H` 只写入 `m_H`，不进入 `buf`/`m_L`（否则初始观察即泄露）。

### 2.3 动作集合

```
A = A_L ⊎ A_I
```

**低可见动作 `A_L`**（进入观察）：
- `out(v)`：向 `buf` 追加公开值 `v ∈ O`；
- `pub_call(t, args_L)`：公开工具调用，参数全为 Low；工具身份 `t` 低可见；
- `pub_ret(v)`：公开工具返回 `v`；
- `halt`：进入 `DONE`；
- `stuck`：进入 `STUCK`（无合法后续）。

**内部/秘密动作 `A_I`**（不进入观察，须满足 AM1）：
- `read_H`：从 `m_H` 读秘密值到内部临时量（不写 `buf`/`m_L`）；
- `secret_call(t, args_H)`：秘密参数工具调用，工具身份与参数均不公开；
- `internal`：内部状态更新（不改 `buf`、`m_L`、`term`）；
- `τ`：静步。

### 2.4 转移关系

```
δ : S × A → 𝒫(S)        （有限非空子集；空集表示该动作不可用）
```

确定性特例：`|δ(s,a)| ≤ 1`。非确定性用来表示工具返回的多种可能、调度选择、LLM 输出的不确定性（**本模型把 LLM 不确定性抽象为非确定性转移，不对无限状态空间建模**）。

一致性公理（沿用 D1 的 AM1，`[定义]`）：

> **AM1**：若 `a ∈ A_I`，则对所有 `s' ∈ δ(s,a)`：`buf(s') = buf(s)`、`m_L(s') = m_L(s)`、`term(s') = term(s)`。

即：秘密动作不得直接改变低可见分量。任何违反 AM1 的动作必须重分类为 `A_L`——否则模型把显式泄露伪装成内部动作。

### 2.5 低观察与终止

```
Obs_L(s) = buf(s)        （只看公开输出缓冲；pc/m_H/tool 可隐藏）
status(s) = term(s)
obs(π) = (lowEffect(a₁),…,lowEffect(a_k), status(s_k))
```

终止与不终止处理（`[定义]`）：
- `DONE`：显式 `halt` 到达；`STUCK`：无可用动作且未 halt；`RUN`：在 T 步内既未 halt 也未 stuck。
- `C_T` 只比较 `≤ T` 步内的 `obs`；**不声称** T 步之后的任何性质。
- 一边 `DONE`、一边 `STUCK` 或 `RUN` ⇒ `obs` 不同 ⇒ `C_T` 失败（这是严格但明确的选择）。

## 3. Agent 机制到模型分量的映射

| Agent 现象 | 模型表示 | 敏感级别 |
| --- | --- | --- |
| Agent 内部记忆读取 | `read_H : m_H → internal` | High，动作入 `A_I` |
| 工具调用 | `pub_call(t,args_L)` 或 `secret_call(t,args_H)` | 参数决定 A_L/A_I |
| 工具返回结果 | `pub_ret(v)` 入 `buf`，或内部返回入 `m_H` | 由返回可见性决定 |
| 公开输出 | `out(v)` 追加 `buf` | Low |
| 高敏感数据 | `x_H`、`m_H` | High，隐藏 |
| 低敏感上下文 | `x_L`、`m_L`、`buf` | Low |
| 跨会话记忆 | 建模为 `m_H` 的一部分（`[待验证]` 本模型只覆盖单会话内） | High |
| 时序/步数侧信道 | 不显式建模；若需覆盖，须把步数并入 `obs`（见 D1 反例 II） | `[待验证]` |

**注意**：控制依赖（if h then out("A") else out("B")）在模型中表现为 `read_H` + 不同 `out(v)` 分支；由于 `out` 是 `A_L` 且值不同，`obs` 不同，`C_T` 会正确判失败。**前提是采集器/模型构建者把分支结果记为 `out(v)` 的真实值**——这一步的真实性不在 ZK 证明内。

---

## 4. 模型能力边界（明确不覆盖）

1. **不建模无限状态 LLM**：把 LLM 输出抽象为有限 `O` 上的非确定性转移，是简化假设。
2. **不证明模型真实性**：`C_T(M)` 成立只说明这个 M 满足有界 NI。
3. **不覆盖跨会话记忆传播**（除非显式塞入 `m_H` 且给出有限域）。
4. **不覆盖隐式时序侧信道**，除非扩展 `obs`。
5. **不覆盖 declassification**：两元素格、无降级（沿用 Phase 1C）。
6. **不把 `T` 之后的性质纳入结论**。

## 5. 一个可直接用于反例的具体实例

```
PC = {s₀, s₁, halt}
M_L = {⊥}, M_H = {0,1}, O = {"OK","A","B"}, T = 3
A_L = {out("OK"), out("A"), out("B"), halt}
A_I = {read_H, τ}

δ(s₀, read_H) = {s₁}                       （m_H 被读取但不写 buf）
δ(s₁, out("OK")) = {halt-state},  δ(halt-state, halt) = {DONE}
```

对 `h=0` 与 `h=1`，`obs` 都是 `("OK", DONE)` ⇒ `C_3(M)=1`。此实例将用于 D4 的不完备性讨论（同一模型能否被候选不变量证明）。

---

## 6. 小结

本模型把"有界非干扰性"落到一个有限状态、有限输入、有限步长的可判定对象上。它是**研究载体**，不是真实 Agent 的证明。任何后续 ZK 证书只能证明 `C_T(M)`，不能替代对 M 本身的验证。
