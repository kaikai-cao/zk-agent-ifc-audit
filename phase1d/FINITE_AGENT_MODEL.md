# Phase 1D.1 — D2：最小有限状态 Agent 模型（Errata 修正版）

证据标记：`[定义]`、`[数学推导]`、`[待验证]`。本文件只定义模型，不声称模型忠实描述任何真实 Agent。

> **本轮修订（Phase 1D.1）**：按任务包 D1–D3 统一为**有限标记转移系统（LTS）+ 弱转移语义**。撤回旧版 `δ : S×A→𝒫(S)` 的"空集歧义"表示、`lowEffect(a)=ε` 的序列内 ε、以及 `Sync` 强制逐字同步内部动作的做法。旧版内容由 `phase1d1/ERRATA.md` 逐条记录。

---

## 1. 设计目标与边界

**目标**：定义一个足够承载"有界非干扰性"研究问题、又不把无限状态 LLM 当作已解决对象的最小模型。

**边界声明（`[定义]`）**：
> 我们证明的是**给定有限模型 M 的性质** `C_T(M)`。这**不**自动证明 M 忠实描述了某个真实 Agent 的执行；从真实执行到 M 的映射（抽象、采样、完整性）属于模型验证/信任边界，不在本证明关系内。这与 Phase 1C `SECURITY_MODEL.md` 的"采集器完整性未被 ZKP 消除"同构，只是上移到模型层。**模型承诺 ≠ 模型真实性。**

## 2. 模型的统一定义

### 2.1 有限 LTS

```
M = (S, Λ, →, Init, Obs, Term, X_L, X_H, T)
```

| 分量 | 含义 |
| --- | --- |
| `S` | 有限状态集合 |
| `Λ` | 有限**低可观察标签**集合，`τ ∉ Λ` |
| `→ ⊆ S × (Λ ∪ {τ}) × S` | 有限分支标记转移关系，记 `s —a→ s'`（`a ∈ Λ ∪ {τ}`） |
| `Init : X_L × X_H → S` | 初始状态函数 |
| `Obs : S → O` | 当前低观察（例如公开输出缓冲 `buf`） |
| `Term : S → {RUN, DONE, STUCK}` | 终止状态信息 |
| `X_L`, `X_H` | 有限低输入集、有限高输入集 |
| `T ∈ ℕ` | **可观察动作数**上界 |

**内部动作统一投影为 `τ`**：原 `A_I` 中的 `read_H`、`secret_call`、`internal`、`τ` 静步全部归入唯一的 `τ` 标签。原 `A_L` 中的 `out(v)`、`pub_call(t,args_L)`、`pub_ret(v)`、`halt`、`stuck` 映射为 `Λ` 中的低标签。这样做的原因：`I_k` 的匹配条件只应区分"低可观察 / 不可观察"，不应区分内部动作的具体种类；内部动作的种类差异不进入观察，因此不进入证明关系。

### 2.2 动作可用性与非确定性（`[定义]`）

不用 `δ(s,a) = ∅` 表示不可用（旧版在空集与"动作存在但无后继"之间有歧义），改为：

```
Enabled(s) = { a ∈ Λ ∪ {τ} | ∃ s' ∈ S : s —a→ s' }
```

- `a ∈ Enabled(s)` 当且仅当 `s` 至少有一个 `a`-后继。
- **非确定性**：`|{s' : s —a→ s'}|` 可为任意有限数；工具返回的多种可能、调度选择、LLM 输出的不确定性都表示为多个后继。
- **所有后继均参与证明**：证书的匹配条件是 ∀后继-∃匹配后继（见 `INDUCTIVE_CERTIFICATE.md`），不允许证明者只挑一个。
- 若保留 `δ` 记号作简写，必须满足 `δ(s,a) = ∅ ⟺ a ∉ Enabled(s)`；本轮其后继集合一律指 `{s' : s —a→ s'}`。

### 2.3 弱转移（`[定义]`，本轮核心）

记 `→^τ*` 为 `—τ→` 的自反传递闭包。对 `ℓ ∈ Λ`：

```
s ⇒^ℓ t   ⟺   ∃ u, v ∈ S :  s —τ→* u  ∧  u —ℓ→ v  ∧  v —τ→* t
```

同时记 `s ⇒^ε t ⟺ s —τ→* t`。

**语义要点（`[定义]`）**：
1. 弱转移允许两条执行在公开动作**之前和之后**有不同数量的内部步骤；不强制逐步同步 `τ`。
2. **内部动作数量不计入 `T`**；`T` 只限制可观察动作（即 `Λ` 中标签）的数量。
3. **`τ`-divergence 默认不作为观察差异**：纯 `τ` 无限循环不产生新的可见标签，因而不进入观察轨迹集合。若要对无限内部循环敏感，必须另行引入 divergence-sensitive 语义（例如把发散标记加入 `Λ`），**不能默认包含在本定理里**。
4. 空 `τ` 序列是合法的：`s ⇒^ε s` 恒成立。

### 2.4 状态结构（作为有限性的具体载体）

为便于把 Agent 现象映射到模型，`S` 可取六元组：

```
s = (pc, m_L, m_H, tool, buf, term)
```

| 分量 | 含义 | 敏感级别 |
| --- | --- | --- |
| `pc` | 控制位置，有限集 `PC` | 可低可见或隐藏，按策略 |
| `m_L` | 低上下文内存，有限域 `M_L` | Low |
| `m_H` | 高敏感内存，有限域 `M_H` | **High（隐藏）** |
| `tool` | 工具调用状态：`idle` 或 `(t, args, pending)` | 参数可含 High |
| `buf` | 公开输出缓冲区，`O` 上长度 ≤ T 的串 | Low |
| `term` | `{RUN, DONE, STUCK}` | Low |

有限性：`PC, M_L, M_H, O, Λ, T` 全有限 ⇒ `S` 有限，`|S| ≤ |PC|·|M_L|·|M_H|·|ToolState|·|O|^{≤T}·3`。

**初始化**：`Init(x_L,x_H) = (pc₀, x_L, x_H, idle, ε, RUN)`。`x_H` 只写入 `m_H`，不进入 `buf/m_L`，否则初始观察即泄露。

### 2.5 观察函数与缓冲一致性（`[定义]`，本轮修复）

**关键修正**：撤销旧版 `obs(π) = (lowEffect(a₁),…,lowEffect(a_k), status)` 中把 `ε` 留在序列里的写法。新定义：

对有限具体执行 `π = s₀ —a₁→ s₁ —a₂→ … —a_n→ s_n`：

```
visibleTrace(π) = 从 (a₁,…,a_n) 中删除所有 τ 后得到的 Λ* 序列
obs(π)          = ( visibleTrace(π), Term(s_n) )
```

`visibleTrace` 是**投影后重新拼成的序列**，因此不可能出现 `(ℓ₁, ε, ℓ₂)` 这种元素；`(ℓ₁,ε,ℓ₂)` 与 `(ℓ₁,ℓ₂)` 是同一个观察序列 `ℓ₁ℓ₂`，不再被当作不同观察。

**`buf` 与可见动作序列的对应（`[定义]`，消除"一处状态观察、一处轨迹观察"的断裂）**：

```
AM0（观察一致性）:
  s —τ→ s'    ⇒  Obs(s') = Obs(s)
  s —ℓ→ s' (ℓ∈Λ) ⇒  Obs(s') = Obs(s) · ℓ     （右追加；Obs 取 buf 时）
```

由 AM0 对执行归纳可得：**`Obs(s_n) = Obs(s₀) · visibleTrace(π)`**。即轨迹观察中的 `visibleTrace(π)` 与状态观察 `Obs(s_n)` 是同一信息的两种记法：前者是增量序列，后者是累积缓冲，二者由初始缓冲唯一连接。终止信息 `Term(s_n)` 是轨迹观察中与状态观察共享的第二个分量（`Term` 不写入 `buf`，故不在 `visibleTrace` 内）。

**AM0 的可检验性**：AM0 是关于模型构造的公理，不是 ZK 证明自动给出的结论。验证者若看不到模型，只能检查"被承诺模型满足 AM0 约束"；模型是否真的如此属于信任边界（`[待验证]`）。

### 2.6 终止语义（`[定义]`）

```
Term(s) = DONE   : 成功终止，无可用动作（halt 后）
Term(s) = STUCK  : 死锁，无可用动作但非成功终止
Term(s) = RUN    : 仍有可用动作（含仅有 τ 可用）
```

一致性要求：
- `Term(s) ≠ RUN ⇒ Enabled(s) = ∅`；`Term(s) = RUN ⇒ Enabled(s) ≠ ∅`。
- `DONE` 与 `STUCK` **不同**：一边 `DONE` 另一边 `STUCK` 视为观察差异，证书无法通过（严格但明确的选择）。
- `T` 步内未终止记为 `RUN`，**不区分**"将来会终止"与"超时"；`C_T` 只覆盖 `≤ T` 个可观察动作，不声称 `T` 之后任何性质。

## 3. Agent 机制到模型分量的映射

| Agent 现象 | 模型表示 | 敏感级别 |
| --- | --- | --- |
| Agent 内部记忆读取 | `—τ→`，`m_H` 变化不写 `buf` | High，动作投影为 τ |
| 工具调用 | `—ℓ→`（公开参数）或 `—τ→`（秘密参数） | 参数决定标签 |
| 工具返回结果 | 可见返回 `—ℓ→` 写 `buf`；秘密返回 `—τ→` 写 `m_H` | 由返回可见性决定 |
| 公开输出 | `—ℓ→` 追加 `buf` | Low |
| 高敏感数据 | `x_H`、`m_H` | High，隐藏 |
| 低敏感上下文 | `x_L`、`m_L`、`buf` | Low |
| 跨会话记忆 | 建模为 `m_H` 的一部分（`[待验证]` 本模型只覆盖单会话） | High |
| 时序/步数侧信道 | **默认不建模**（τ 数与步数不计入观察）；若需覆盖，必须把 `tick` 提升为 `Λ` 中的可见标签，不能用"步数"偷渡进 `obs`（见 `PROPERTY_DEFINITIONS.md` 反例 II） | `[待验证]` |

**控制依赖**（`if h then out("A") else out("B")`）：表现为 `—τ→` 读 `m_H` 后走不同 `—ℓ→` 分支；因 `ℓ` 不同，`obs` 不同，`C_T` 正确判失败。**前提是模型构建者把分支结果记为真实的 `ℓ`**——该真实性不在 ZK 证明内。

---

## 4. 模型能力边界（明确不覆盖）

1. **不建模无限状态 LLM**：把 LLM 输出抽象为有限 `Λ` 上的非确定性转移，是简化假设。
2. **不证明模型真实性**：`C_T(M)` 成立只说明这个 M 满足有界 NI。
3. **不覆盖跨会话记忆传播**（除非显式塞入 `m_H` 并给出有限域）。
4. **不覆盖隐式时序侧信道**（除非把 `tick` 提升为 `Λ` 标签）。
5. **不覆盖 τ-divergence 敏感性**（除非引入 divergence-sensitive 语义）。
6. **不覆盖 declassification**：两元素格、无降级。
7. **不把 `T` 之后的性质纳入结论**。

## 5. 用于反例的具体实例

```
PC = {s₀, s₁, halt},  M_L = {⊥}, M_H = {0,1}, O = {"OK","A","B"}, T = 3
Λ = {out(OK), out(A), out(B), halt},  τ ∉ Λ

s₀ —τ→ s₁                         （读 m_H，但不写 buf）
s₁ —out(OK)→ s₂
s₂ —halt→ s₃,  Term(s₃)=DONE
```

对 `h=0` 与 `h=1`，`visibleTrace` 都是 `out(OK)`，`Term` 都是 `DONE`，故 `obs` 相同 ⇒ `C_3(M)=1`。该实例显示：内部读秘密本身不造成观察差异，**前提是无控制依赖分支**。

---

## 6. 小结

本模型把"有界非干扰性"落到一个**有限 LTS + 弱转移 + 可观察动作计数**的可判定对象上。三个关键点：

1. 内部动作统一投影为 `τ`，`τ` 不计入 `T`，允许两侧内部步数不同；
2. `obs(π) = (visibleTrace(π), Term(last(π)))`，`visibleTrace` 删除全部 `τ`，序列中无 ε；
3. 动作可用性用 `Enabled(s)` 与转移关系表示，非确定性后继全部参与证明。

它是**研究载体**，不是真实 Agent 的证明。任何后续 ZK 证书只能证明 `C_T(M)`，不能替代对 M 本身的验证。
