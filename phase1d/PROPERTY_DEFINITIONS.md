# Phase 1D — D1：A/B/C 三类性质的严格定义与逻辑关系

证据标记：`[定义]`（本文件约定）、`[数学推导]`、`[原文核验]`、`[待验证]`。本轮不改电路、不跑实验。

> **对 Phase 1C 的修正声明**：Phase 1C `DECISION.md` 写过"研究问题在定义层面成立且严格强于现有 A"。本文件撤回这一"严格强于"表述。A、C 作用于**不同对象**（单图 vs 有限模型），在没有额外完备性假设时**不可比较**；既不能说 C 严格强于 A，也不能说 A 严格强于 C。

## 1. 统一执行模型（供三类性质共用记号）

有限状态 Agent 模型（D2 将完整定义）：

```
M = (S, X_L, X_H, Init, δ, A_L, A_I, Obs_L, status, T)
```

- `S` 有限状态集；`X_L` 有限低输入集；`X_H` 有限高输入集。
- `Init : X_L × X_H → S` 初始状态函数。
- `A = A_L ⊎ A_I`；`A_L` 为低可见动作，`A_I` 为内部/秘密动作（含秘密读取、秘密工具调用参数、τ 静步）。
- `δ : S × A → 𝒫(S)` 有限分支转移关系（确定性是 `|δ(s,a)| ≤ 1` 的特例）。
- `Obs_L : S → O` 单状态低观察；`status(s) ∈ {RUN, DONE, STUCK}`。
- `T ∈ ℕ` 执行长度上界。

**低效应投影**（关键定义，`[定义]`）：

```
lowEffect(a) = a   若 a ∈ A_L
lowEffect(a) = ε   若 a ∈ A_I        （ε = 无低可见效应）
```

模型一致性公理 **AM1**：若 `a ∈ A_I`，则对所有 `s' ∈ δ(s,a)` 有 `Obs_L(s') = Obs_L(s)` 且 `status` 不因该动作从 DONE/STUCK 变为 RUN。不满足 AM1 的模型必须把该动作重分类为 `A_L`。

执行片段（trace）`π = (s₀,a₁,s₁,…,a_k,s_k)`，`s₀ = Init(x_L,h)`，`s_i ∈ δ(s_{i-1},a_i)`，`k ≤ T`。

**轨迹低观察**（`[定义]`）：

```
obs(π) = ( lowEffect(a₁), …, lowEffect(a_k), status(s_k) )
```

即：只保留低可见动作序列与终态类别。`A_I` 静步不进入 `obs`，因此**两条允许不同长度的执行可以有相同 `obs`**。

**可达观察集**：

```
ObsSet_k(M, x_L, h) = { obs(π) : π 为从 Init(x_L,h) 出发、长度 ≤ k 的执行片段 }
```

## 2. 性质 A：Trace-level IFC

**输入对象**：一条执行轨迹 τ 及其信息流图 `G = (V, E, label, type)`（由采集器从 τ 构造，`E ⊆ V×V×{data,control}`，`label : V→{Low,High}`，`type` 含 `public_sink`）。

**性质定义**（`[定义]`，沿用 `docs/TRACE_IFC_RELATION.md`）：

```
A(G) = 1  ⟺  ¬∃ h ∈ H, l ∈ Sinks_L : h ⇝ l
```

其中 `H = {v : label(v)=High}`，`Sinks_L = {v : type(v)=public_sink ∧ label(v)=Low}`，`⇝` 为忽略边种类的有向可达。

**量词结构**：对**单张图**内部所有路径的全称否定（`¬∃path`）。它不对模型 `M`、不对其他输入、不对未发生的执行作任何断言。

**确定性/长度/终止**：与 A 无关——A 只检查已给定的静态图，不解释执行语义；图来自哪条轨迹、轨迹多长、是否终止，都在 A 的定义域之外。

## 3. 性质 B：Relational trace property（双轨迹）

**输入对象**：两条执行轨迹 `τ₀, τ₁`，满足指定配对条件 `Pair(τ₀,τ₁)`：相同 `x_L`，高输入 `h₀ ≠ h₁`（或由挑战者指定），两者均为 `M` 的合法执行。

**性质定义**（`[定义]`）：

```
B(τ₀, τ₁) = 1  ⟺  Pair(τ₀,τ₁) ∧ obs(τ₀) = obs(τ₁)
```

**量词结构**：`∃(τ₀,τ₁)`（若证明者自选对）或"对指定对"（若挑战绑定）。**不是** `∀h₀∀h₁`。

- 若证明者自选对且允许 `h₀ = h₁`，B 平凡成立 → 定义必须禁止该退化（`h₀ ≠ h₁` 且对由验证者挑战绑定）。
- B 是**单个关系实例**的判定，不是系统级性质。

**确定性/长度/终止**：B 对两者分别允许不同长度（由 `obs` 忽略 `A_I` 静步实现）；终止类别进入 `obs`，故一边 DONE、一边 STUCK 会使 B 失败。非确定性下 B 可定义为"存在配对"或"观察集相等"，必须显式选择；下文采用**观察集相等**版本以便与 C 对齐。

## 4. 性质 C：Bounded universal noninterference

**输入对象**：模型 `M`、低输入 `x_L`、上界 `k ≤ T`。

**性质定义**（`[定义]`）：

```
C_k(M) = 1  ⟺  ∀ x_L ∈ X_L, ∀ h₀,h₁ ∈ X_H :
                  ObsSet_k(M, x_L, h₀) = ObsSet_k(M, x_L, h₁)
```

**量词结构**：`∀x_L ∀h₀ ∀h₁`（全称、跨执行、关于模型语义）。这是经典 NI 的**有界、 possibilistic（集合相等）**版本：

- 有界：只在 `k ≤ T` 步内；`C_T` 成立**不**蕴含无限执行上的 NI。
- 集合相等：非确定性下要求两侧可能观察集合相同，强于"每条 τ₀ 存在某条 τ₁"的单侧模拟，弱于带概率分布的定量 NI。
- 终止：DONE/STUCK 进入 `obs`；`k` 步内未终止记为 RUN，不区分"将来终止"与"超时"（`[待验证]` 若需区分，须扩展 `status`）。

**确定性模型中的等价形式**：若 `δ` 确定，则 `ObsSet` 为单元素集，`C_k` 退化为 `∀x_L,h₀,h₁: obs(π(h₀)) = obs(π(h₁))`，即标准两运行 NI 的有界版。

## 5. 逻辑关系：可证明的蕴含与不可比较

### 5.1 可证明的蕴含（`[数学推导]`）

1. **C ⇒ B（条件）**：若 B 的配对来自 `M` 的合法执行且挑战绑定 `h₀≠h₁`，则由 `C_T` 的 `ObsSet` 相等，任一 `τ₀` 的观察都在 `τ₁` 侧有对应，故 B 对指定对成立。反向不成立：一个对相等不给出全称。
2. **C_{k+1} ⇒ C_k**：观察集随步数单调扩展，但全称等式在更短上界自动成立。
3. **B ∧ 额外全称化 ⇒ C**：若把 B 的判定对 `X_H × X_H` 全部枚举且全部通过，则得到 C。这正是"枚举路径"的本质（见 COMPLEXITY_COMPARISON.md）。

### 5.2 不可比较：两个必要反例

**反例 I（有 High→Low 路径，但低观察不泄露秘密）**

```
x_L = "summarize";  h ∈ {0,1}
s₀ --read(h)--> s₁ --derive(t)--> s₂ --out("OK")--> DONE
图 G：h --data--> t --control--> sink       （采集器记录两条依赖边）
```
- `A(G)=0`：存在 `h → t → sink` 路径。
- `C_T(M)=1`：两高输入的 `obs` 均为 `("OK", DONE)`。
- 结论：`C` 真而 `A` 假 ⇒ **C ⇏ A**。图**过近似**了真实语义依赖（存在不产生输出差异的"死依赖"）。

**反例 II（秘密影响低观察，但图中无对应依赖边）**

```
h = 0: s₀ --τ--> s₁ --out("OK")--> DONE
h = 1: s₀ --τ--> τ --> s₁ --out("OK")--> DONE
低观察若包含步数（时序侧信道）：obs(h=0) = (out("OK"), DONE, len=2)
                              obs(h=1) = (out("OK"), DONE, len=3)
采集器仅记录显式数据流，无 h 到任何节点的边 → G 中无 High→Low 路径
```
- `A(G)=1`：图中无路径。
- 若 `obs` 含时序则 `C_T(M)=0`。
- 结论：`A` 真而 `C` 假 ⇒ **A ⇏ C**。图**欠近似**了真实语义依赖（隐式/时序通道未记录）。

> 边界声明：若把 `obs` 定义为不含时序，反例 II 中 `C=1`，反例失效。这说明 **A 与 C 的关系依赖观察函数定义**，不能脱离 `Obs_L` 谈强弱。

### 5.3 使 A 与 C 可比的额外假设（`[数学推导]`）

| 假设 | 内容 | 得到的蕴含 |
| --- | --- | --- |
| **AM2 图完备性** | 任何使低观察不同的语义影响都在 `G` 中留下路径 | `A(G)=1 ⇒ C_T(M)=1`（A ⇒ C） |
| **AM3 无虚假边** | `G` 中每条 High→Low 路径都对应真实输出差异 | `C_T(M)=1 ⇒ A(G)=1`（C ⇒ A） |
| **AM2 ∧ AM3** | 图与语义依赖严格对应 | `A ⇔ C` |

AM2/AM3 都不由当前采集器保证：反例 I 违反 AM3，反例 II 违反 AM2（这与 Phase 1C 反例 3、NeuroTaint 的"语义转换/隐式因果/跨会话记忆"缺口一致，`[原文核验]` arXiv:2604.23374 摘要）。

### 5.4 A/B/C 对照表（修正版）

| 维度 | A | B | C |
| --- | --- | --- | --- |
| 输入对象 | 单图 G | 两条轨迹 τ₀,τ₁ | 模型 M + x_L |
| 量词 | `¬∃path`（图内） | `∃` 指定对 | `∀x_L∀h₀∀h₁` |
| 跨执行 | 否 | 是（一对） | 是（全体） |
| 确定性依赖 | 无 | 需定义配对 | 确定/非确定均可 |
| 不同长度 | 不适用 | 允许（`obs` 忽略静步） | 允许（观察集） |
| 终止处理 | 不适用 | status 入 obs | status 入 obs |
| 与经典 NI | 不等价 | 必要非充分 | 有界 possibilistic 版本 |
| 强弱关系 | 与 C 不可比较 | 弱于 C | 在 AM2/AM3 下才与 A 可比 |

## 6. 本文件结论

1. A/B/C 是**三个不同对象上的三个不同性质**，不构成线性强弱链。
2. Phase 1C 的"严格强于"表述撤回；正确关系是"在 AM2/AM3 下可比较，否则不可比较"。
3. C 的证明目标应明确为 `C_T`：有界、观察集相等、终止入观察。
4. 后续归纳证书必须证明的是 `C_T`，而不是 A，也不是 B；若证书只覆盖被挑战的一对，它证明的是 B，不是 C。
