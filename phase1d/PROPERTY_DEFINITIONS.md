# Phase 1D.1 — D1：A/B/C 三类性质的严格定义与逻辑关系（Errata 修正版）

证据标记：`[定义]`、`[数学推导]`、`[原文核验]`、`[待验证]`。本轮不改电路、不跑实验。

> **沿用并强化 Phase 1D 的修正声明**：Phase 1C `DECISION.md` 的"研究问题在定义层面严格强于现有 A"已撤回。A、C 作用于**不同对象**（单图 vs 有限模型），在没有额外完备性假设时**不可比较**。本轮进一步统一记号到有限 LTS + 弱转移语义，使 C 的定义不再依赖 `ε` 序列与"步数"偷渡。

---

## 1. 统一执行语义（供三类性质共用记号）

采用 `FINITE_AGENT_MODEL.md` 的有限 LTS：

```
M = (S, Λ, →, Init, Obs, Term, X_L, X_H, T)
```

- `S` 有限；`Λ` 有限低可观察标签，`τ ∉ Λ`。
- `→ ⊆ S × (Λ ∪ {τ}) × S` 有限分支转移关系。
- `Enabled(s) = { a ∈ Λ ∪ {τ} | ∃ s' : s —a→ s' }`。
- `Init : X_L × X_H → S`；`Obs : S → O`；`Term : S → {RUN, DONE, STUCK}`。
- `T ∈ ℕ` 限制**可观察动作**数量，不限制 `τ` 数量。

**弱转移（`[定义]`）**：

```
s ⇒^ℓ t   ⟺   ∃ u,v : s —τ→* u ∧ u —ℓ→ v ∧ v —τ→* t      (ℓ ∈ Λ)
s ⇒^ε t   ⟺   s —τ→* t
```

**具体执行与观察（`[定义]`，本轮修复）**：

```
π = s₀ —a₁→ s₁ —a₂→ … —a_n→ s_n     (s₀ = Init(x_L,h), a_i ∈ Λ ∪ {τ})
visibleTrace(π) = delete_τ(a₁,…,a_n) ∈ Λ*
obs(π)          = ( visibleTrace(π), Term(s_n) )
```

`delete_τ` 是**投影后重新拼接**，因此 `(ℓ₁,ε,ℓ₂)` 与 `(ℓ₁,ℓ₂)` 是同一序列；序列内不存在 ε 元素。

**有界可达观察集（`[定义]`）**：

```
Tr_k(s) = { obs(π) | π 为从 s 出发的具体执行, |visibleTrace(π)| ≤ k }
Tr_k(M, x_L, h) = Tr_k(Init(x_L,h))
```

**AM0（观察一致性，`[定义]`）**：`s —τ→ s' ⇒ Obs(s')=Obs(s)`；`s —ℓ→ s' ⇒ Obs(s')=Obs(s)·ℓ`。由此 `Obs(s_n)=Obs(s₀)·visibleTrace(π)`，状态观察与轨迹观察一致（详见 `FINITE_AGENT_MODEL.md` §2.5）。

## 2. 性质 A：Trace-level IFC

**输入对象**：一条执行轨迹 `τ` 及其信息流图 `G = (V, E, label, type)`（由采集器从 `τ` 构造，`E ⊆ V×V×{data,control}`，`label : V→{Low,High}`，`type` 含 `public_sink`）。

**性质定义（`[定义]`，沿用 `docs/TRACE_IFC_RELATION.md`）**：

```
A(G) = 1  ⟺  ¬∃ h ∈ H, l ∈ Sinks_L : h ⇝ l
```

`H = {v : label(v)=High}`，`Sinks_L = {v : type(v)=public_sink ∧ label(v)=Low}`，`⇝` 为忽略边种类的有向可达。

**量词结构**：对**单张图**内部所有路径的全称否定（`¬∃path`）。不对 `M`、不对其他输入、不对未发生执行作任何断言。

**确定性/长度/终止**：与 A 无关——A 只看已给定的静态图，不解释执行语义。

---

## 3. 性质 B：Relational trace property（双轨迹）

**输入对象**：两条具体执行 `π₀, π₁`，满足配对条件 `Pair(π₀,π₁)`：相同 `x_L`，`h₀ ≠ h₁`（**必须**由挑战者绑定，不能由证明者自选），两者均为 `M` 的合法执行。

**性质定义（`[定义]`）**：

```
B(π₀, π₁) = 1  ⟺  Pair(π₀,π₁) ∧ obs(π₀) = obs(π₁)
```

**量词结构**：`∃(π₀,π₁)` 或"对指定对"。**不是** `∀h₀∀h₁`。若允许证明者自选且 `h₀=h₁`，B 平凡成立 → 定义必须禁止退化（Phase 1C 已指出，此处保留）。

**确定性/长度/终止**：允许两条执行 `τ` 步数不同（`visibleTrace` 删除 `τ`）；终止类别进入 `obs`，一边 `DONE` 一边 `STUCK` 使 B 失败。非确定性下 B 可定义为"存在配对"或"观察集相等"，两种不同，必须显式选择；本文件采用**单对观察相等**作为 B 的原始定义，"观察集相等"留给 C（避免把 B 和 C 混为一谈）。

---

## 4. 性质 C：Bounded universal noninterference

**输入对象**：模型 `M`、`x_L`、上界 `k ≤ T`。

**性质定义（`[定义]`）**：

```
C_k(M) = 1  ⟺  ∀ x_L ∈ X_L, ∀ h₀,h₁ ∈ X_H :
                  Tr_k(M, x_L, h₀) = Tr_k(M, x_L, h₁)
```

**量词结构**：`∀x_L ∀h₀ ∀h₁`（全称、跨执行、关于模型语义）。这是经典 NI 的**有界、possibilistic（集合相等）**版本：

- **有界**：只覆盖 `≤ k` 个可观察动作；`C_T` 成立**不**蕴含无限执行上的 NI，也不蕴含 `T` 之后的行为。
- **集合相等**：非确定性下要求两侧可能观察集合相同，强于"每条 `π₀` 存在某条 `π₁`"的单侧包含，弱于带概率分布的定量 NI。
- **终止**：`Term` 进入 `obs`（作为第二个分量）；`k` 个可观察动作内未终止记为 `RUN`。
- **τ 不计入观察**：纯 `τ` 步不产生可见标签，因此不同 `τ` 长度的执行可具有相同 `obs`；`τ`-divergence 不构成观察差异（见 `FINITE_AGENT_MODEL.md` §2.3）。

**确定性特例**：若每个 `Enabled(s)` 至多一个标签且每个标签至多一个后继，`Tr_k` 为单元素集，`C_k` 退化为标准两运行 NI 的有界版。

**与 B 的关系（`[数学推导]`）**：`C_k(M) ⇒` 任意挑战绑定的合法对满足 B；反向不成立。B 是单例判定，C 是模型级全称性质。

## 5. 逻辑关系：可证明的蕴含与不可比较

### 5.1 可证明的蕴含（`[数学推导]`）

1. **`C_T ⇒ B`（条件）**：B 的配对来自 `M` 合法执行且挑战绑定 `h₀≠h₁` 时，`Tr_T` 相等保证任一 `π₀` 的观察在 `π₁` 侧有对应。反向不成立。
2. **`C_{k+1} ⇒ C_k`**：观察集随可观察步数单调扩展，全称等式在更短上界自动成立（`τ` 不消耗预算）。
3. **枚举路径 ⇒ C**：把 B 的判定对 `X_H × X_H` 全部枚举并通过，得到 C（本质是枚举路径，见冻结文档 `COMPLEXITY_COMPARISON.md`）。
4. **归纳证书 ⇒ C**：若存在满足 `INDUCTIVE_CERTIFICATE.md` 的 `I₀..I_T`，则 `C_T`（见 `SOUNDNESS_PROOF.md`，本轮给出完整证明）。这是充分条件，非必要条件。

### 5.2 不可比较：两个必要反例

**反例 I（有 High→Low 路径，但低观察不泄露秘密）**

```
x_L = "summarize";  h ∈ {0,1}
s₀ —τ(read h)→ s₁ —τ(derive t)→ s₂ —out(OK)→ s₃ —halt→ DONE
图 G：h —data→ t —control→ sink        （采集器记录两条依赖边）
```

- `A(G)=0`：存在 `h → t → sink` 路径。
- `C_T(M)=1`：两高输入的 `obs` 同为 `(out(OK)·halt, DONE)`。
- `C` 真而 `A` 假 ⇒ **`C ⇏ A`**。图**过近似**了语义依赖（存在不产生输出差异的死依赖）。

**反例 II（秘密影响低观察，但图中无对应依赖边）**

```
h=0: s₀ —τ→ s₁ —out(OK)→ DONE
h=1: s₀ —τ→ τ → s₁ —out(OK)→ DONE
```

若观察包含步数，旧版写 `obs(h=0)=(out(OK),DONE,len=2)`、`obs(h=1)=(...,len=3)`。**本轮修正**：在新语义下 `τ` 数与步数**默认不进入 `obs`**，因此上述两执行 `obs` 相同，反例 II **在默认语义下失效**。要让它成立，必须显式把时序提升为可见标签：

```
扩展 Λ' = Λ ∪ {tick}，且 h=0 侧不发 tick，h=1 侧在第二个 τ 处发一次 tick
⇒ obs(h=0) = (out(OK), DONE),  obs(h=1) = (tick, out(OK), DONE)
⇒ C_T(M') = 0
```

采集器若只记录显式数据流，图中仍无 High→Low 路径 ⇒ `A(G)=1`，`C` 假 ⇒ **`A ⇏ C`**。图**欠近似**了语义依赖（隐式/时序通道未记录）。

> **边界声明**：A 与 C 的关系依赖 `Λ` 与 `Obs` 的定义。**不能脱离观察函数谈强弱**；把通道提升为可见标签会改变结论。这不是缺陷，而是"观察边界属于信任模型"的直接后果。

### 5.3 使 A 与 C 可比的额外假设（`[数学推导]`）

| 假设 | 内容 | 得到的蕴含 |
| --- | --- | --- |
| **AM2 图完备性** | 任何使低观察不同的语义影响都在 `G` 中留下路径 | `A(G)=1 ⇒ C_T(M)=1` |
| **AM3 无虚假边** | `G` 中每条 High→Low 路径都对应真实输出差异 | `C_T(M)=1 ⇒ A(G)=1` |
| **AM2 ∧ AM3** | 图与语义依赖严格对应 | `A ⇔ C` |

AM2/AM3 都不由当前采集器保证：反例 I 违反 AM3，反例 II（扩展 Λ 后）违反 AM2。这与 Phase 1C 记录的隐式流/跨会话记忆缺口一致（`[原文核验]` arXiv:2604.23374 摘要）。

### 5.4 A/B/C 对照表（修正版）

| 维度 | A | B | C |
| --- | --- | --- | --- |
| 输入对象 | 单图 `G` | 两条具体执行 `π₀,π₁` | 模型 `M` + `x_L` |
| 量词 | `¬∃path`（图内） | 指定对（单例） | `∀x_L∀h₀∀h₁` |
| 跨执行 | 否 | 是（一对） | 是（全体） |
| 确定性依赖 | 无 | 需定义配对 | 确定/非确定均可 |
| 不同长度 | 不适用 | 允许（τ 不进观察） | 允许（`Tr_k` 是集合） |
| 终止处理 | 不适用 | `Term` 入 `obs` | `Term` 入 `obs` |
| 与经典 NI | 不等价 | 必要非充分 | 有界 possibilistic 版本 |
| 强弱关系 | 与 C 不可比较 | 弱于 C | 在 AM2/AM3 下才与 A 可比 |

## 6. 本文件结论

1. A/B/C 是**三个不同对象上的三个不同性质**，不构成线性强弱链。
2. Phase 1C 的"严格强于"表述已撤回；正确关系是"在 AM2/AM3 下可比较，否则不可比较"。
3. C 的证明目标明确为 `C_T`：**有界（按可观察动作计数）、观察集相等、`Term` 入观察、τ 不进观察**。
4. 后续归纳证书必须证明 `C_T`，而不是 A，也不是 B；若证书只覆盖被挑战的一对，它证明的是 B，不是 C。
5. **本轮修复**：`obs` 序列内不再有 ε；时序侧信道默认不建入，须显式提升为 `Λ` 标签才能讨论。
