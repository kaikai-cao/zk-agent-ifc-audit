# Phase 1D — 总结裁决

日期：2026-11-27。范围：`zk-agent-ifc-audit` 的归纳证书路线是否值得进入 Halo2 原型。本轮只做数学定义、构造与理论比较，未改电路、未跑实验、未提交历史分支。

---

## 1. 裁决

> ## **STOP**
>
> 当前归纳证书路线**不进入 Halo2 原型**。理由不是"构造失败"，而是：**数学内核是标准的有界互模拟（bisimulation）**，紧凑性与完备性不可兼得，且 **ZK 的不可替代价值依赖一个尚未建立的硬隐藏需求**。三个阻断项中，前两项得到条件性回答，第三项没有令人信服的答案——按任务包规则，不得进入原型。

这不是"理论没做扎实"。相反，本轮把理论问题做扎实后的结论就是：这条路线的理论增量不足以支撑密码学原型。

## 3. 三个阻断项的正面回答

### 阻断项 1：Soundness 依赖哪些模型假设？

**回答**：AM1–AM6，逐条列在 `SOUNDNESS_PROOF.md` §3 表格。核心是：

- **AM1**（内部动作不改低可见分量）——若不满足，定理假；
- **AM2**（一侧可用的 `A_L` 在另一侧也可用）——原候选条件**遗漏**，本轮补上；
- **AM5**（后继配对完整）——漏列后继直接破坏 soundness；
- **AM6**（观察函数固定公开）——否则证明的命题与预期不符。

结论是**条件性 soundness**，不是无条件安全证明。这一项已回答，但代价是定理带六个假设。

### 阻断项 2：证书是否覆盖所有允许的秘密输入，而非证明者挑的一小部分？

**回答**：形式上有——(Init) 条件写为 `∀x_L∀h₀∀h₁ : I_T(Init(x_L,h₀),Init(x_L,h₁))`，量词覆盖整个 `X_H²`。但这**只在电路真正对 `h₀,h₁` 全称化时成立**；若实现让证明者提交具体 `h₀,h₁`，则退化为 B（单例对），是 soundness 漏洞。本轮只给出定义要求，**未验证任何实现**；在原型前这是一个开放的实现风险，不是已闭合项。

### 阻断项 3：与普通 self-composition、bisimulation、Lean 验证相比，ZK 提供什么不可替代价值？

**回答（最关键）**：**没有找到不可替代的价值。**

- 普通 self-composition（公开模型 + 符号高输入）已能证明全称 NI，无需 ZK；
- bisimulation（公开关系）已给出同样结构的关系证明；
- LLMbda 已在 Lean 中机器检验全称概率 NI（`[原文核验]` arXiv:2602.20064 v2）；
- 归纳证书的数学内容 = 有界互模拟 + `Obs⁺` 绑定 + 有界索引，前两项是标准结论；
- ZK 唯一可能的增量是"隐藏 `I` 与 `δ`"。但：
  1. 没有任何场景建立"必须隐藏模型/不变量，否则不可接受"的硬需求（Phase 1C 停止条件 5 未闭合）；
  2. 若隐藏模型，验证者只能相信"某个被承诺模型满足约束"，无法确认它忠实描述真实 Agent——模型来源信任问题仍在；
  3. 固定电路模板可能要求按最坏 `N_max,T` 构建，抵消紧凑性收益。

按任务包的明示规则："三个问题没有得到令人信服的回答，就不能进入 Halo2 原型。"第三项未通过。

## 4. 为什么是 STOP 而不是 REVISE

REVISE 的含义是"理论有价值，但构造需要修正"。本轮确实修正了两处构造（AM2 补入、Step 改双向集合匹配），但STOP 的理由更强：

1. **内核非新**：归纳证书就是有界互模拟，任务包已明确要求在这种情况下诚实承认"密码学只是包装"；
2. **紧凑性有条件**：`SOUNDNESS_PROOF.md` §4.2 与 `COMPLEXITY_COMPARISON.md` §5 证明"紧凑 + 完备"不可兼得，P3 优势只在 `I` 恰好简洁时成立，不是普遍优势；
3. **价值命题未闭合**：ZK 的不可替代价值依赖未建立的硬隐藏需求；
4. **上游裁决未闭合**：Phase 1C 裁决为 REVISE，前置闸门 R3（相对已有工作的新可证性质）与 R5（硬隐私需求）本轮**均未通过**。

因此：理论问题已做扎实，结论是**当前路线不值得进入 Halo2 原型**。

## 5. 什么情况下可以重开（不是本轮结论）

只有同时满足以下条件，才值得重新评估（不构成当前 GO）：

1. 给出一个具体场景，证明"公开模型或不变量会造成不可接受损害"（闭合 Phase 1C R5）；
2. 证明在该场景下，`I` 有远小于 `|S|²T` 的简洁表示，且对目标模型类足够；
3. 给出固定电路模板下仍保持紧凑的构造，并说明模型来源信任如何处理；
4. 明确相对 self-composition + bisimulation 的新可证性质，而非仅换证明系统。

在此之前，不写 Halo2 电路，不新增原型分支，不扩展实验。

## 6. 对任务包最终问题的直接回答

> "能否把一个全称的关系安全性质，转化为一个具有紧凑证书、可由 SNARK 验证、同时隐藏敏感模型信息的证明问题？"

**回答**：
- **数学上可以**：`C_T` 可转化为 `I₀..I_T` 证书（D3/D4），且 Init 条件对 `X_H` 全称；
- **紧凑性有条件**：`I` 简洁时比枚举省，但简洁 `I` 不完备，完备 `I` 回到 `Ω(N²)`；
- **SNARK 可验证性可以**：三个条件是算术化的候选，但本轮未验证固定模板成本；
- **隐藏敏感模型可以，但价值未证**：ZK 能隐藏 `I`/`δ`，但没有硬需求说明这种隐藏不可替代，且隐藏后模型真实性更不可核查。

综合：**技术上可行，研究上不够**。这正是 STOP 的理由——不是做不到，而是做到了也不构成足够的研究贡献。
