## 1. 定理陈述

**定理 1（Bounded Weak Bisimulation Soundness，`[定理]`）**

设有限 LTS `M` 满足 AM0–AM3，设 `I₀,…,I_T` 满足 (OBS)+(BASE)+(TAU)+(STEP)+(INIT)。则对任意 `x_L ∈ X_L`、`h₀,h₁ ∈ X_H`：

```
Tr_T( Init(x_L,h₀) ) = Tr_T( Init(x_L,h₁) )
```

即 `C_T(M) = 1`。

**限定（`[数学推导]`）**：
- 结论只覆盖 `≤ T` 个**可观察动作**；`τ` 数不限，不声称无限执行 NI、`T` 之后行为、概率 NI、或真实 Agent 的性质。
- 结论是 `Tr_T` **集合相等**（possibilistic），不是概率分布相等。
- 定理是**条件性**的：依赖 AM0–AM3 与证书条件；脱离这些假设不能宣称"证明了 NI"。

## 2. 三个辅助引理

### 引理 1（τ 段对齐，`[证明]`）

**陈述**：若 `I_k(s₀,s₁)`，且 `π₀` 是从 `s₀` 出发的有限纯 τ 执行 `s₀ —τ→ … —τ→ t₀`，则存在从 `s₁` 出发的有限纯 τ 执行 `π₁` 到某 `t₁`，使 `I_k(t₀,t₁)`。

**证明**：对 `π₀` 的 τ 步数 `n` 归纳。

- `n=0`：`t₀=s₀`，取 `π₁` 为零步执行，`t₁=s₁`，`I_k(s₀,s₁)` 由假设成立。∎（基底）
- `n→n+1`：写 `π₀ = s₀ —τ→ s₀' · α'`，其中 `α'` 是从 `s₀'` 出发的 `n` 步纯 τ 执行到 `t₀`。由 (TAU-fwd) 于 `I_k(s₀,s₁)` 与 `s₀ —τ→ s₀'`，得 `∃ s₁' : s₁ ⇒^ε s₁' ∧ I_k(s₀',s₁')`。把 `s₁ ⇒^ε s₁'` 展开为有限纯 τ 执行（定义即有限 τ*），以其终点 `s₁'` 为新起点；由归纳假设于 `I_k(s₀',s₁')` 与 `α'`，得 `∃ t₁ : s₁' ⇒^ε t₁ ∧ I_k(t₀,t₁)`。由 `⇒^ε = —τ→*` 的传递性拼接两段，得从 `s₁` 到 `t₁` 的有限纯 τ 执行。∎

### 引理 2（单个可观察步对齐，`[证明]`）

**陈述**：若 `I_{k+1}(s₀,s₁)` 且 `s₀ ⇒^ℓ s₀'`（`ℓ ∈ Λ`），则 `∃ s₁' : s₁ ⇒^ℓ s₁' ∧ I_k(s₀',s₁')`。

**证明**：直接取 (STEP-fwd) 于 `ℓ, s₀'`。（对称方向用 (STEP-bwd)。）∎

### 引理 3（执行对齐主引理，`[证明]`）

**陈述**：若 `I_k(s₀,s₁)`，且 `π₀` 是从 `s₀` 出发的具体执行，`m = |visibleTrace(π₀)| ≤ k`，则存在从 `s₁` 出发的具体执行 `π₁`，使：

```
visibleTrace(π₁) = visibleTrace(π₀)
Term(last(π₁))   = Term(last(π₀))
I_{k-m}( last(π₀), last(π₁) )
```

**证明**：对 `m` 归纳，内层用引理 1 处理 τ 段。

**基底 `m=0`**：`π₀` 为纯 τ 执行到 `t₀`。由引理 1（当前 `k`）得 `π₁` 纯 τ 执行到 `t₁` 且 `I_k(t₀,t₁)`。由 (OBS) 得 `Term(t₀)=Term(t₁)`；两侧 `visibleTrace` 均为 `ε`；`k-m=k`。∎

**归纳步骤 `m>0`**：把 `π₀` 唯一分解为

```
π₀ = α · (v —ℓ→ w) · β
```

其中 `α` 是从 `s₀` 到 `v` 的纯 τ 前缀，`ℓ ∈ Λ` 是 `π₀` 的**第一个**可观察标签，`β` 是从 `w` 到 `t₀ = last(π₀)` 的剩余执行，`|visibleTrace(β)| = m-1`。

1. 由引理 1 于 `I_k(s₀,s₁)` 与 `α`，得纯 τ 执行 `α₁ : s₁ ⇒^ε u`，且 `I_k(v,u)`。
2. `v —ℓ→ w` 是弱转移 `v ⇒^ℓ w`（前后 τ* 取零步）。由 (STEP-fwd) 直接于 `I_k(v,u)`（当前预算 `k ≥ 1`，消耗一步后为 `k-1`，即引理 2 的索引特例）得 `∃ u' : u ⇒^ℓ u' ∧ I_{k-1}(w,u')`。把 `u ⇒^ℓ u'` 展开为具体段 `u —τ→* p —ℓ→ q —τ→* u'`。
3. `β` 是从 `w` 出发、`m-1 ≤ k-1` 个可观察动作的执行。由归纳假设于 `I_{k-1}(w,u')` 与 `β`，得从 `u'` 出发的 `β₁`，满足 `visibleTrace(β₁)=visibleTrace(β)`、`Term(last(β₁))=Term(t₀)`、且 `I_{k-1-(m-1)}=I_{k-m}(t₀,last(β₁))`。
4. 拼接 `π₁ = α₁ · (u —τ→* p —ℓ→ q —τ→* u') · β₁`。则：

```
visibleTrace(π₁) = ε · ℓ · visibleTrace(β₁) = ℓ · visibleTrace(β) = visibleTrace(π₀)
Term(last(π₁))   = Term(last(β₁)) = Term(t₀)
I_{k-m}(last(π₀), last(π₁))   由步骤 3
```

∎

## 3. 定理 1 的完整证明

**步骤 1（`k=0` 的观察一致性）**：由 (BASE)，`I₀(s₀,s₁) ⇒ Obs(s₀)=Obs(s₁) ∧ Term(s₀)=Term(s₁)`。从 `s₀` 出发 0 个可观察动作的执行只能是纯 τ 执行；由引理 1（`k=0`）匹配到 `s₁` 的纯 τ 执行，由 (BASE) 于终点得 `Term` 相等，`visibleTrace` 均为 `ε` ⇒ `obs` 相等。这给出 `Tr₀(s₀) ⊆ Tr₀(s₁)`；对称方向用 (TAU-bwd) 同理。

**步骤 2（归纳假设）**：设对某 `k`，`I_k(s₀,s₁) ⇒ Tr_k(s₀) = Tr_k(s₁)`（由步骤 4、5 证明，此处作为结构假设）。

**步骤 3（对任一可观察转移做匹配）**：取任意 `obs₀ ∈ Tr_{k+1}(s₀)`，对应执行 `π₀`，`m = |visibleTrace(π₀)| ≤ k+1`。由 (OBS) 于 `I_{k+1}(s₀,s₁)` 得当前观察与终止一致。由引理 3（当前预算 `k+1`）得 `π₁` 从 `s₁` 出发，`visibleTrace(π₁)=visibleTrace(π₀)`、`Term` 相等、且 `I_{k+1-m}(last(π₀),last(π₁))`。若 `m>0`，(STEP-fwd) 提供同标签 `ℓ` 的匹配后继；若 `m=0`，由 (TAU-fwd) 处理。

**步骤 4（双向包含）**：
- `⊆`：由上一步的 `π₁` 直接满足 `obs(π₁)=obs₀`，故 `obs₀ ∈ Tr_{k+1}(s₁)` ⇒ `Tr_{k+1}(s₀) ⊆ Tr_{k+1}(s₁)`。
- `⊇`：对称地使用 (TAU-bwd) 与 (STEP-bwd)（引理 1/2/3 的对称版）得 `Tr_{k+1}(s₁) ⊆ Tr_{k+1}(s₀)`。

**步骤 5（集合相等）**：由双向包含 ⇒ `Tr_{k+1}(s₀) = Tr_{k+1}(s₁)`。归纳闭合。

> **说明**：步骤 2–5 的归纳实际由引理 3 一次完成（引理 3 已内含对 `m` 的归纳，不依赖步骤 2 的外部假设）。此处按任务包要求展开为可读的七步结构；形式化时可直接以引理 3 为单一归纳命题，避免双重归纳。

**步骤 6（结论）**：取 `k = T`。

**步骤 7（初始化全称）**：对任意 `x_L ∈ X_L`、`h₀,h₁ ∈ X_H`，由 (INIT) 得 `I_T(Init(x_L,h₀), Init(x_L,h₁))`。由引理 3（`k=T`，`m ≤ T`）：

```
Tr_T(Init(x_L,h₀)) = Tr_T(Init(x_L,h₁))
```

对**所有** `x_L,h₀,h₁` 成立，即 `C_T(M)`。∎

## 4. 终止、长度、非确定性与可用性处理（`[数学推导]`）

- **终止**：`Term` 是 `obs` 的第二分量，(OBS) 强制一致。`DONE vs RUN/STUCK`、`DONE vs STUCK` 都使 `I_k` 不成立 ⇒ 证书拒绝。若两侧都 `DONE` 但达到 `DONE` 的 `τ` 数不同 ⇒ `visibleTrace` 与 `Term` 均相同，允许（引理 1 吸收 τ）。
- **不同长度**：`τ` 数差异由引理 1（`(TAU)` + `⇒^ε` 含零步）与 `⇒^ℓ` 的前后 `τ*` 吸收；**只能**对齐内部步差异，不能对齐可观察标签数量差异（后者由 (STEP) 同标签要求严格禁止）。旧版 stuttering 公理 `s ∈ δ(s,τ)` **不再是必需假设**——(TAU) 已允许 `⇒^ε` 取零步。
- **非确定性**：(STEP-fwd) 对 `s₀` 的**每个** `⇒^ℓ` 后继要求匹配，(STEP-bwd) 对 `s₁` 的每个后继要求匹配 ⇒ 得到 `Tr_T` 集合相等而非单向包含。证明者只挑一个后继的漏洞被 ∀ 量词堵住。
- **动作可用性（防真空通过）**：`Enabled(s)` 明确定义，"无后继"不是"动作不可用"。若 `s₀` 有标签 `ℓ` 而 `s₁` 无 `⇒^ℓ` 后继，(STEP-fwd) 的 ∃ 失败；若 `s₁` 有而 `s₀` 无，(STEP-bwd) 失败。若 `I_k(s₀,s₁)` 且 `s₀ —τ→ s₀'`、`s₁` 无 τ 后继，则 (TAU-fwd) 允许 `s₁'=s₁`（零步），但必须 `I_k(s₀',s₁)` ⇒ 由 (OBS) `Term/Obs` 不变；若 `s₀'` 进入 `DONE/STUCK` 而 `s₁` 仍 `RUN`，(OBS) 失败 ⇒ 正确拒绝。
- **`τ`-divergence**：纯 τ 无限循环不产生 `Λ` 标签，不在 `Tr_T` 中；默认不构成差异。敏感化须扩展 `Λ`，本定理不覆盖。

## 5. 不完备性：`[反例]` trace-equivalent but not bisimilar

### 5.1 撤回旧反例

旧 §4.1（状态重命名 `ctr` 0→1→2 vs 2→1→0）与 §4.2（不同 `pc` 标号 `p₀→p₁` vs `q₀→q₁`）**只证明"浅层/受限形式的 I 不够"**：若允许任意二元关系（把对应状态列入 `I`），两者都可证明。它们**不构成**对 `I_k` 证书形式的不完备性证明，本轮撤回为正式反例的地位。

### 5.2 新反例（完整状态转移表）

设 `Λ = {a,b,c}`，无 τ，终止状态为吸收态，`Obs` 为累计标签串。

**左侧系统（对应 `h₀`）**：

| 状态 | 出边 | `Term` | `Obs` |
| --- | --- | --- | --- |
| `s` | `s —a→ a₁`, `s —a→ a₂` | RUN | `ε` |
| `a₁` | `a₁ —b→ b₁` | RUN | `a` |
| `a₂` | `a₂ —c→ c₁` | RUN | `a` |
| `b₁` | 无 | DONE | `ab` |
| `c₁` | 无 | DONE | `ac` |

**右侧系统（对应 `h₁`）**：

| 状态 | 出边 | `Term` | `Obs` |
| --- | --- | --- | --- |
| `t` | `t —a→ u` | RUN | `ε` |
| `u` | `u —b→ b₂`, `u —c→ c₂` | RUN | `a` |
| `b₂` | 无 | DONE | `ab` |
| `c₂` | 无 | DONE | `ac` |

（把两系统视为同一 `M` 在两个高输入 `h₀,h₁` 下的展开；`Init(x_L,h₀)=s`，`Init(x_L,h₁)=t`。）

### 5.3 验证两边 trace set 相等（`[数学推导]`）

```
Tr_2(s) = { (ε,RUN), (a,RUN), (ab,DONE), (ac,DONE) }
Tr_2(t) = { (ε,RUN), (a,RUN), (ab,DONE), (ac,DONE) }
```

- 左侧：`s` 自身给 `(ε,RUN)`；经 `a` 到 `a₁` 或 `a₂` 给 `(a,RUN)`；再经 `b` 或 `c` 分别给 `(ab,DONE)`、`(ac,DONE)`。
- 右侧：`t` 自身给 `(ε,RUN)`；经 `a` 到 `u` 给 `(a,RUN)`；`u` 经 `b`/`c` 给 `(ab,DONE)`、`(ac,DONE)`。

⇒ `C_2(M) = 1`（对这一对高输入成立；`T=2` 时即为 bounded NI）。

### 5.4 证明不存在满足要求的 bisimulation（`[数学推导]`）

反设存在关系 `R` 满足 (OBS)+(STEP) 且 `(s,t) ∈ R`。本例无 τ，(TAU) 与弱转移退化为强转移，故 (STEP) 就是标准强互模拟条件。

1. `s —a→ a₁`。由 (STEP-fwd) 于 `(s,t)` 与后继 `a₁`，需 `∃ t' : t —a→ t' ∧ (a₁,t') ∈ R`。`t` 的唯一 `a`-后继是 `u` ⇒ **`(a₁,u) ∈ R`**。
2. `s —a→ a₂`。同理 ⇒ **`(a₂,u) ∈ R`**。
3. 考察 `(a₁,u) ∈ R`。`u —c→ c₂`。由 (STEP-fwd) 需 `∃ s' : a₁ —c→ s' ∧ (s',c₂) ∈ R`。但 `a₁` 无 `c`-后继 ⇒ **矛盾**。
4. （对称地，考察 `(a₂,u)` 与 `u —b→ b₂` 同样矛盾。）

⇒ 不存在任何 `R` 使 `(s,t)` 互模拟。故不存在满足 (OBS)+(TAU)+(STEP) 且满足 (INIT) 的证书 `I₀..I_T`（因为 (INIT) 强制 `I_2(s,t)`）。

### 5.5 结论与边界（`[数学推导]`）

- 该反例证明：**bounded weak bisimulation 证书严格强于 `C_T`（bounded trace equivalence）**——目标性质成立但证书不存在。
- 因此 §1 定理是**充分非必要**条件，`I_k` 对 `C_T` **不完备**。
- **本反例只能说明"互模拟式证书 ≠ trace equivalence"**，**不能**证明"所有紧凑证书都不存在"。是否存在其他关系证书（例如 trace 自动机、集合级关系、分区细化）能以更紧凑形式证明该例，本轮**不主张任何结论**（`[待验证]`）。
- 原 §4.3 "紧凑 I 与完备 I 不可兼得"的普遍断言**撤回**：本轮不提供正式复杂度假设、归约或下界，故降级为待研究假设。冻结文档 `COMPLEXITY_COMPARISON.md` §5 与 `DECISION.md` 中同类表述因范围冻结不修改，只在 `phase1d1/ERRATA.md` 记录。

### 5.6 增强路径（不主张下界，`[数学推导]`）

可能提升表达能力的方向（均未证明充分/必要/复杂度）：
1. **集合级关系**：`I ⊆ 𝒫(S)×𝒫(S)`，允许"一侧一个后继对应另一侧后继集合"；
2. **trace 自动机证书**：提交接受 `Tr_T` 的自动机而非状态关系；
3. **多个不变量析取**：`I = ⋃_j I^j`，覆盖不同分支模式；
4. **有界枚举**：`T` 小、状态少时直接枚举，放弃紧凑性。

这些方向的规模/完备性权衡是**开放问题**，不是本轮结论。

## 6. 隐私代价（`[数学推导]`）

`I_k` 越 expressive，越可能编码 `m_H`/工具参数的对应关系。若 `I_k` 作为见证提交且 ZK 隐藏，验证者看不到——但电路必须能检查 `I_k` 的约束，要求 `I_k` 以结构化形式（判定电路/查找表）存在；结构化 `I_k` 的形状（状态数、分支模式）本身可能泄露模型规模信息。这是"证书表达能力 vs 隐藏模型细节"的张力（`[待验证]`）。

**SNARK 隐藏的确切对象**：`I_k` 的取值、可选的 `→` 结构、`h₀,h₁` 的具体值；**不隐藏**公开输入 `x_L`、`T`、`Λ`、以及"被承诺模型满足约束"这一事实。它**不解决**模型来源信任（见 `INDUCTIVE_CERTIFICATE.md` §6、`DECISION.md` 阻断项 3）。

## 7. 三个阻断项的回答

1. **Soundness 依赖哪些模型假设？** AM0–AM3（§0 表）+ 证书条件 (OBS)/(BASE)/(TAU)/(STEP)/(INIT)。AM0（观察一致性）与 (INIT) 全称是最容易在实现中丢失的两项；缺失即定理不成立。
2. **证书是否覆盖所有秘密输入？** 由 (INIT) 的 `∀h₀∀h₁` 覆盖；若只检查挑出的对则只证 B。**必须在实现中把 `h₀,h₁` 作为任意见证并对 `X_H` 全称化**，否则是 soundness 漏洞——不是紧凑化技巧。
3. **ZK 提供什么不可替代价值？** 本轮**不新增**结论：公开 self-composition / bisimulation 已给出同样的关系证明结构，Lean 已给机器检验；ZK 的价值仅在"必须隐藏模型且验证者仍需可信判断"的场景，而该硬需求尚未建立（Phase 1C 停止条件 5）。见冻结文档 `DECISION.md`（本轮不修改）。

---

## 8. 结论

- 定理 1 在 AM0–AM3 + 五组证书条件下成立；证明覆盖 k=0 基底、τ 段对齐、可观察步双向匹配、集合双向包含、初始化全称，共七步。
- `I_k` 是 bounded weak bisimulation 证书 ⇒ `C_T`，**充分非必要**。
- 新反例（trace-equivalent but not bisimilar）给出具体的不完备性实例，旧的"紧凑/完备不可兼得"普遍断言撤回。
- soundness 是条件性的，不能宣称无条件 NI 安全证明，也不能宣称无限执行 NI。
