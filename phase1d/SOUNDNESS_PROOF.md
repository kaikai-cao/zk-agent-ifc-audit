证据标记：`[定理]`、`[证明草案]`、`[数学推导]`、`[反例]`、`[待验证]`。

## 1. 定理陈述

**定理 1（归纳证书 ⇒ 有界 NI，`[定理]`）**

设有限模型 `M` 满足 D2 的 AM1（内部动作不改低可见分量）与 stuttering 公理（`s ∈ δ(s,τ)`）。设有界证书 `I₀,…,I_T` 满足 D3 的全部条件：

- (Init) `∀x_L ∀h₀,h₁ : I_T(Init(x_L,h₀), Init(x_L,h₁))`；
- (Step) D3 §3.2 的双向集合保持条件；
- (Obs) `I₀(s₀,s₁) ⇒ Obs⁺(s₀)=Obs⁺(s₁)`。

则对任意 `x_L ∈ X_L`、`h₀,h₁ ∈ X_H`：

```
C_T(M) :  ObsSet_T(M,x_L,h₀) = ObsSet_T(M,x_L,h₁)
```

即 M 满足有界、观察集相等的非干扰性。

**重要限定（`[数学推导]`）**：
- 结论只覆盖 `≤ T` 步；不声称无限执行 NI。
- 结论是 `ObsSet` **集合相等**（possibilistic NI），不是概率分布相等、不是几乎必然 NI。
- 结论关于**给定模型 M**，不关于真实 Agent（模型真实性不在证明内）。

## 2. 证明草案

### 2.1 辅助引理 A：单步低观察一致性（`[证明草案]`）

**引理 A**：若 `I_{k+1}(s₀,s₁)` 且 `Sync(a₀,a₁)` 且两者可用，则对任意配对后继 `s₀' ∈ δ(s₀,a₀)`、`s₁' ∈ δ(s₁,a₁)` 且 `I_k(s₀',s₁')`，有：

```
lowEffect(a₀) = lowEffect(a₁)     且      Obs⁺(s₀') 与 Obs⁺(s₁') 一致到 k 步
```

**证明**：
- `lowEffect` 相等由 Sync (1)(2)(3)：若 `a₀ ∈ A_L`，则 `a₁=a₀`，故 lowEffect 相等；若同为 `A_I`，则两者 lowEffect 均为 `ε`，相等。条件 (4) 保证 `τ` 对齐。
- `I_k(s₀',s₁')` 由 Step (a) 的存在性给出。
- 若 `k=0`，由 (Obs) 得 `Obs⁺(s₀')=Obs⁺(s₁')`。∎

### 2.2 辅助引理 B：k 步观察集保持（`[证明草案]`）

**引理 B（归纳命题）**：对任意 `k ≤ T`，若 `I_k(s₀,s₁)`，则

```
ObsSet_k(s₀) = ObsSet_k(s₁)
```

这里 `ObsSet_k(s)` 表示从状态 s 出发、≤ k 步的执行片段的 `obs` 集合。

**归纳基底 `k=0`**：
从 s 出发 0 步的唯一片段观察是 `(status(s))`（无低动作）。由 (Obs)，`term(s₀)=term(s₁)`，故两者 `ObsSet_0` 相同。∎

**归纳步骤 `k → k+1`**：
设 `I_{k+1}(s₀,s₁)`，需证 `ObsSet_{k+1}(s₀) = ObsSet_{k+1}(s₁)`。分两个包含方向。

**方向 ⊆（取 `π₀` 从 `s₀`，找 `π₁` 从 `s₁`）**：

1. 若 `π₀` 长度为 0：观察为 `(term(s₀))`；(Obs) 给 `term(s₁)=term(s₀)`，从 `s₁` 取 0 步片段即可。
2. 若 `π₀` 首步为 `a₀` 到 `s₀'`：
   - 若 `a₀ ∈ A_L`：Sync (1) 强制 `a₁=a₀`；因 `a₀` 在 `s₀` 可用且 `I₀` 给 `buf(s₀)=buf(s₁)`、`term` 相同，需假定 `a₀` 在 `s₁` 也可用——这是**必须的额外模型假设 AM2**（见 §3）。取该 `a₁`，由 Step (a) 存在 `s₁' ∈ δ(s₁,a₁)` 且 `I_k(s₀',s₁')`，由归纳假设得剩余 k 步观察集相等。由引理 A，`lowEffect(a₀)=lowEffect(a₁)`，拼接后 `obs(π₀)=obs(π₁)`。
   - 若 `a₀ ∈ A_I`：取 `a₁=τ`（若 `a₀=τ` 则取 `a₁=τ`，满足 Sync (4)；若 `a₀` 为其他内部动作，Sync (3) 允许 `a₁` 为任一 `A_I`，取 `τ`）。因 stuttering 公理 `s₁ ∈ δ(s₁,τ)`，Step (a) 要求存在 `I_k(s₀',s₁')` 的后继；AM1 保证 `buf` 不变，低观察序列该步为 `ε`，不产生差异。归纳假设处理剩余。
   - 若 `a₀` 在 `s₀` 可用但 `s₁` 无可用 `a₁` 满足 Sync：这种情况被 Step 的前提排除（Step 要求对**所有**满足 Sync 且两侧可用的动作对成立）；若 `s₁` 根本没有可用动作，则 `term(s₁)=STUCK`，与 `I₀` 推出的 `term(s₀)=term(s₁)` 矛盾（`s₀` 有可用动作 ⇒ `term(s₀)=RUN`）。故该情形不发生。
3. 拼接得到 `π₁`，且 `obs(π₁)=obs(π₀)`。故 `ObsSet_{k+1}(s₀) ⊆ ObsSet_{k+1}(s₁)`。

**方向 ⊇**：完全对称，用 Step (b)。∎

### 2.3 定理 1 的推出（`[证明草案]`）

对任意 `x_L,h₀,h₁`，由 (Init) 得 `I_T(Init(x_L,h₀), Init(x_L,h₁))`。由引理 B（`k=T`）：

```
ObsSet_T(Init(x_L,h₀)) = ObsSet_T(Init(x_L,h₁))
```

对所有 `x_L,h₀,h₁` 成立，即 `C_T(M)`。∎

### 2.4 终止与长度处理（`[数学推导]`）

- **终止**：`halt` 属 `A_L`，Sync (1)(2) 要求同步；`term ∈ Obs⁺` 由 (Obs) 约束。故一边 `DONE` 另一边 `RUN/STUCK` 时 `I` 不成立，证书无法通过——正确拒绝违反 NI 的情形。
- **不同长度**：由 stuttering（`s ∈ δ(s,τ)`）与 Sync (4)（`τ` 对 `τ`），较短执行可插入 `τ` 与较长执行对齐；`τ` 不进入 `obs`，故观察相等。注意：**只能对齐内部步差异**，不能对齐低动作数量差异（后者由 Sync (1)(2) 严格禁止）。
- **T 步内未终止**：记为 `RUN`，两侧同为 `RUN` 即一致；不推断 T 之后行为。

### 2.5 非确定性配对（`[数学推导]`）

Step (a)(b) 的双向全称-存在条件等价于在转移关系上存在一个 `I`-全关系（total relation），这是 bisimulation 的标准形式（`[原文核验]` 经典 bisimulation 定义：状态对关系满足转移匹配）。因此：

- 单向 (a) 只给 `ObsSet(s₀) ⊆ ObsSet(s₁)`（模拟，simulation）；
- 双向 (a)(b) 给集合相等（bisimulation 式），正是 `C_T` 所需；
- 若模型确定，`δ` 单值，(a)(b) 退化为单后继匹配。

## 3. 可靠性依赖的模型假设（阻断项 1 的正面回答）

| 编号 | 假设 | 若不成立会怎样 |
| --- | --- | --- |
| AM1 | `A_I` 动作不改 `buf/m_L/term` | 内部动作可偷偷输出，`Obs⁺` 一致性失效，定理假 |
| AM2 | `I₀` 相等时，一侧可用的 `A_L` 动作在另一侧也可用 | 引理 B 步骤 2 失败；可在 Init/Step 中显式检查，但若模型不满足则证书无法建立 |
| AM3 | stuttering：`s ∈ δ(s,τ)` | 不同长度执行无法对齐 |
| AM4 | `X_H` 有限且 Init 条件对其全称成立 | 只覆盖部分高输入 ⇒ 只证 B 不证 C（阻断项 2） |
| AM5 | `δ` 有限分支，证书提供完整后继配对 | 漏列后继 ⇒ 集合相等不成立（soundness 漏洞） |
| AM6 | 观察函数 `Obs_L` 固定且公开 | 观察函数被替换 ⇒ 证明的命题与预期不同 |

**结论**：定理 1 的 soundness 是**条件性**的——"(Init)+(Step)+(Obs) ⇒ C_T" 在 AM1–AM6 下成立；**不能**脱离这些假设宣称证明了 NI。这与 Phase 1C 的诚实边界一致。

## 4. 不完备性分析：证书形式无法证明的满足 NI 的模型

### 4.1 反例 3（具体，`[反例]`）：需要"状态重命名"的等价

设 `M` 有两个高输入 `h₀,h₁`，状态空间除 `m_H` 外另有一个内部计数器 `ctr ∈ {0,1,2}`（不进入 `buf`）。

```
h₀ 路径: ctr 0→1→2，在 ctr=2 时 out("OK")
h₁ 路径: ctr 2→1→0，在 ctr=0 时 out("OK")
```

- `C_T(M)=1`：两条执行 `obs` 都是 `("OK", DONE)`，观察集相等（`[数学推导]`）。
- 但 D3 的 `I` 要求 `I(s₀,s₁)` 时 `buf` 与 `term` 相同；在中间步 `buf` 均为空、`term` 均为 RUN，故 `I₀` 可以成立。问题在 **Step**：`Sync(τ,τ)` 后，`δ` 的 `ctr` 更新方向相反（0→1 vs 2→1）。若把 `ctr` 视为状态的一部分，`I_k` 必须对 `(ctr=1 from h₀, ctr=1 from h₁)` 成立——这本身没问题。
- 构造一个真正失效的版本：令 `ctr` 的取值域不同——`h₀` 侧为 `{0,1,2}`，`h₁` 侧为 `{a,b,c}`，转移函数名不同但低观察相同。`I` 若被限制为"同构位置相等"的浅层形式则失败；若允许任意二元关系（把 `0↔a, 1↔b, 2↔c` 列入 `I`），仍可证明。

**这个反例说明浅层 `I` 不够，但完备的二元关系形式仍可证明**——需要给出真正不可证明的例子。

### 4.2 反例 4（真正的不可证明性，`[反例]`）：关系性质需要"跨路径关联"

设 `M` 的高输入 `h ∈ {0,1}` 决定两次**独立**的内部随机选择 `r₁,r₂ ∈ {0,1}`（非确定性地展开为 4 条执行）。公开输出规则：

```
若 r₁ = r₂ : out("OK")
若 r₁ ≠ r₂ : 先 out("OK") 再 out("OK")       （两次同样输出）
```

即：`h=0` 与 `h=1` 都产生相同的输出多重集，但**输出发生在路径的不同阶段**（由 `r₁⊕r₂` 决定何时输出），且 `r₁,r₂` 相关性与 `h` 耦合。

更简洁的反例（`[反例]`，推荐采用）：

设 `M` 对 `h₀,h₁` 的执行集合相同（同一组轨迹），但两条轨迹的**状态标号不同**：

```
S = {p₀,p₁,q₀,q₁},  buf ∈ {ε,"OK"}
h₀: p₀ --τ--> p₁ --out("OK")--> DONE
h₁: q₀ --τ--> q₁ --out("OK")--> DONE
ObsSet 相等：两条轨迹 obs 都是 (out("OK"), DONE)
```

`I` 若被限制为"相同 pc 才相关"（例如电路实现里 `I` 按 pc 索引），则 `p₀` 与 `q₀` 不相关，证书失败。但允许任意 `I(p₀,q₀), I(p₁,q₁)` 即可证明。

**结论（`[数学推导]`）**：不存在对**所有**满足 `C_T` 的模型都完备的"固定浅层 `I` 形式"；完备性只能通过允许 `I` 任意（等价 bisimulation/最大模拟），而那会回到 `O(|S|²)` 规模。**这是不完备性的实质：紧凑性来自限制 `I` 的表达形式，而限制必然带来不可证明的模型。**

### 4.3 增强路径（`[数学推导]`）

1. **增强状态**：把 `ctr` 等内部量加入 `I` 的判定域（`I` 变得更宽），可证明更多模型，但增大证书；
2. **改变关系形式**：从"状态对相等"改为"状态对集合的等价"（set-based bisimulation），可覆盖更多非确定情形，代价是指数级状态集；
3. **多个不变量**：`I¹,…,Iᵐ` 析取覆盖不同路径模式，规模随 m 增长；
4. **上界内穷举**：对 `T` 小、状态少的场景直接枚举，放弃紧凑性。

**共同规律**：表达能力 ↑ ⇒ 证书规模 ↑ ⇒ 逼近枚举。不存在既保持 `O(poly)` 紧凑又对全部 `C_T` 模型完备的单一形式（`[推论]`，未形式化证明）。

### 4.4 隐私代价（`[数学推导]`）

`I` 越 expressive，越可能编码 `m_H`/工具参数的对应关系。若 `I` 作为见证提交且 ZK 隐藏，验证者看不到——但电路必须能检查 `I` 的约束，这要求 `I` 以结构化形式（如判定电路）存在；结构化 `I` 的形状（状态数、分支模式）本身可能泄露模型规模信息。这是"证书表达能力 vs 隐藏模型细节"的张力，需要在原型前明确泄露边界（`[待验证]`）。

## 5. 三个阻断项的当前回答

1. **Soundness 依赖哪些模型假设？** AM1–AM6，§3 表格逐条列出；其中 AM2/AM5 必须在证书里显式检查，否则定理不成立。
2. **证书是否覆盖所有秘密输入？** 由 (Init) 的全称条件覆盖；若只检查挑出的对则只证 B。**必须在电路中把 `h₀,h₁` 作为任意见证并对 `X_H` 全称化**，否则是 soundness 漏洞。
3. **ZK 提供什么不可替代价值？** 见 `DECISION.md`：若 `I` 与 `δ` 可公开，普通证明/形式化验证更便宜；ZK 的价值仅在"必须隐藏模型且验证者仍需可信判断"的场景，但该场景的硬需求尚未建立（Phase 1C 停止条件 5）。

## 6. 结论

- 定理 1 在 AM1–AM6 下成立，证明草案给出完整基底/步骤/观察/终止/非确定性处理；
- 不完备性反例 4.2 说明限制 `I` 形式必有不可证明模型，增强表达必增大证书；
- soundness 是条件性的，不能宣称无条件 NI 安全证明。
