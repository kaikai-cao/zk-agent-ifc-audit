# Phase 1D.1 — D3：有界弱互模拟证书 I_k（Errata 修正版）

证据标记：`[定义]`、`[数学推导]`、`[待验证]`。可靠性证明在 `SOUNDNESS_PROOF.md`。

> **本轮核心修订**：撤回旧版单关系 `I(s₀,s₁) ⊆ S×S` 与 `Sync(a₀,a₁)` 逐步锁步同步，改为**有界关系族** `I_k(s₀,s₁)`，`k` 表示剩余可观察动作预算；用弱转移 `⇒^ℓ` 吸收两侧不等的 `τ` 步数；匹配条件改为 ∀后继-∃后继的双向全关系。

---

## 1. 目标与定位

**目标**：对有限 LTS `M`，构造一个比枚举 `|X_H|²` 对执行更紧凑的证书，使验证者相信 `C_T(M)`（有界、观察集相等、τ 不进观察的非干扰性），而不看到敏感模型细节。

**候选证书**：

```
I_k(s₀, s₁) ⊆ S × S ,   0 ≤ k ≤ T
```

`s₀` 来自高输入 `h₀` 的执行，`s₁` 来自 `h₁` 的执行（同 `x_L`）。`I_k` 本身是**证明者秘密见证**；验证者只见承诺与约束检查结果。

**记号**：`Obs(s)` 与 `Term(s)` 直接取 `FINITE_AGENT_MODEL.md` §2.5–2.6 的定义；不再使用旧版 `Obs⁺`。

---

## 2. 为什么旧的 `Sync` 必须撤回（`[数学推导]`）

旧 `Sync(a₀,a₁)` 要求：低动作逐字相同；内部动作同为 `A_I`；**`τ` 对 `τ` 逐步对齐**。三处问题：

1. **`τ` 对 `τ` 强制同步** ⇒ 两侧内部步数必须相等，而弱转移语义明确允许不等。旧版靠 `s ∈ δ(s,τ)` 的 stuttering 公理补步，但那要求先证明 `I_k(s₀',s₁)` 在插入 `τ` 后仍成立——旧证明草案把这一步含混带过（见旧 `SOUNDNESS_PROOF.md` §2.2 步骤 2 的 `a₀ ∈ A_I` 分支）。
2. **`lowEffect(a)=ε` 留在观察序列里**，使 `(ℓ₁,ε,ℓ₂)` 与 `(ℓ₁,ℓ₂)` 被当作不同观察——新定义已删除序列内 ε，旧 `Sync` 的对齐精度失去意义。
3. **动作可用性用 `δ(s,a)=∅` 表示**，在空集与"动作存在但无后继"之间有歧义，且未强制所有非确定性后继参与匹配。

**结论**：用 `⇒^ℓ`（吸收 τ*）+ 全后继匹配条件替换 `Sync`；`τ` 不再有任何同步要求。

---

## 3. `I_k` 的严格定义

对 `0 ≤ k ≤ T`，要求以下四组条件。每组都是**表示性约束**，不是"由归纳法可得"。

### 3.1 当前观察一致（OBS）

```
(OBS)  ∀ k ∈ [0,T], ∀ s₀,s₁ : I_k(s₀,s₁) ⇒
           Obs(s₀) = Obs(s₁)  ∧  Term(s₀) = Term(s₁)
```

**注意**：旧版只在 `k=0` 要求 `Obs⁺` 相等。本版要求**所有 k** 都一致——因为一对 `I_{k+1}` 状态可以先执行 0 个可观察动作（只走 `τ`），此时必须用 (OBS) 得出观察相等；若只在 `k=0` 约束，归纳基底无法覆盖"τ-only 执行段"。

### 3.2 基底（BASE）

```
(BASE) I_0(s₀,s₁) ⇒ [ Obs(s₀)=Obs(s₁) ∧ Term(s₀)=Term(s₁) ]
```

`k=0` 表示**没有剩余可观察动作预算**，因此不能再要求两侧存在下一步公开动作。此时 (BASE) 与 (OBS) 在 `k=0` 处重合；**不**额外要求转移匹配。

### 3.3 内部步匹配（TAU）

`τ` 不消耗可观察预算，故匹配后预算仍为 `k`：

```
(TAU-fwd)  ∀k, I_k(s₀,s₁) ∧ s₀ —τ→ s₀' ⇒
              ∃ s₁' : s₁ ⇒^ε s₁' ∧ I_k(s₀',s₁')

(TAU-bwd)  ∀k, I_k(s₀,s₁) ∧ s₁ —τ→ s₁' ⇒
              ∃ s₀' : s₀ ⇒^ε s₀' ∧ I_k(s₀',s₁')
```

其中 `s ⇒^ε t ⟺ s —τ→* t`（含零步 `t=s`）。**关键点**：允许一侧做多个 `τ` 而另一侧做零个（例如 `s₀ —τ→ s₀'` 匹配 `s₁'=s₁`），这正是"内部步数不同仍可对应"的形式化。匹配后仍须满足 `I_k`，从而由 (OBS) 保证 `Obs/Term` 没被 `τ` 偷偷改变。

### 3.4 可观察步匹配（STEP）

`k+1` 表示还有 `k+1` 个可观察动作预算。弱转移 `⇒^ℓ` 已在两侧吸收各自前后 `τ*`；每消耗一个可观察动作，预算降为 `k`：

```
(STEP-fwd) ∀ℓ∈Λ, ∀s₀' : s₀ ⇒^ℓ s₀' ⇒
              ∃ s₁' : s₁ ⇒^ℓ s₁' ∧ I_k(s₀',s₁')

(STEP-bwd) ∀ℓ∈Λ, ∀s₁' : s₁ ⇒^ℓ s₁' ⇒
              ∃ s₀' : s₀ ⇒^ℓ s₀' ∧ I_k(s₀',s₁')
```

**两条都不能省略**（`[数学推导]`）：
- 缺 (STEP-fwd)：一侧有公开动作而另一侧无对应动作 → 真空通过；
- 缺 (STEP-bwd)：一侧多个非确定性后继时证明者只挑一个 → 得到单侧包含而非集合相等。

**∀后继-∃后继** 覆盖四类漏洞：
1. 一侧存在公开动作、另一侧不存在对应动作 ⇒ 该方向的 ∃ 失败；
2. 一侧有多个非确定性后继 ⇒ **每个**后继都必须有匹配，不能只挑一个；
3. 一侧存在某标签 `ℓ`、另一侧没有该标签 ⇒ 对 `ℓ` 的全称检查失败；
4. `τ` 被错误强制同步 ⇒ 由 `⇒^ℓ` 吸收 `τ*`，(TAU) 独立处理，`τ` 不再进入 (STEP)。

### 3.5 初始化全称（INIT）

```
(INIT)  ∀ x_L ∈ X_L, ∀ h₀,h₁ ∈ X_H :
           I_T( Init(x_L,h₀), Init(x_L,h₁) )
```

**否决替换**（任务包硬约束）：
```
✗ ∃ h₀,h₁ : I_T(Init(x_L,h₀), Init(x_L,h₁))
✗ I_T(Init(x_L,h₀), Init(x_L,h₁))  仅对证明者自选的 X_H 子集成立
```

若允许 `∃` 或自选子集，证书退化为证明 B（单例），不是 C（全称）——这是 soundness 漏洞，不是"紧凑化技巧"。在 SNARK 实现中，`h₀,h₁` 必须是见证中的任意值，且 (INIT) 的约束不得依赖其具体取值（只依赖 `m_H` 被隔离的结构）。

## 4. 完整证书条件汇总

```
I₀..I_T 是证书  ⟺  对所有 k ∈ [0,T]：
  (OBS)   I_k(s₀,s₁) ⇒ Obs(s₀)=Obs(s₁) ∧ Term(s₀)=Term(s₁)
  (BASE)  I₀(s₀,s₁) ⇒ 同上（k=0 实例，不额外要求转移）
  (TAU)   I_k(s₀,s₁) ∧ s₀ —τ→ s₀' ⇒ ∃s₁' : s₁ ⇒^ε s₁' ∧ I_k(s₀',s₁')   （对称）
  (STEP)  I_{k+1}(s₀,s₁) ∧ s₀ ⇒^ℓ s₀' ⇒ ∃s₁' : s₁ ⇒^ℓ s₁' ∧ I_k(s₀',s₁')   （对称）
  (INIT)  ∀x_L∀h₀∀h₁ : I_T(Init(x_L,h₀), Init(x_L,h₁))
```

## 5. 五类同步问题逐一回答（任务包 D3 要求）

**Q1 哪些动作必须"同步"？** 只有 `Λ` 中的可观察标签。`ℓ` 相同才进入 `obs`，`(STEP)` 要求两侧 `⇒^ℓ` 同标签；`Term` 由 (OBS) 强制一致。

**Q2 哪些动作可以不同？** 所有 `τ`（原 `A_I` 全部）：读到的秘密值、秘密工具参数、内部更新都可以不同。(TAU) 只要求 `τ` 匹配 `⇒^ε`（含零步），不要求同类，更不要求同值。

**Q3 工具调用参数是否属于低观察？** 按可见性分类，不按"是不是工具"分类。公开参数 ⇒ 标签 `ℓ ∈ Λ`，必须相同；秘密参数 ⇒ 投影为 `τ`，可不同。混合情形（工具身份公开、参数秘密）必须拆成 `—ℓ→` + `—τ→` 两步，否则模型表达不足（不是密码学问题）。

**Q4 非确定性工具返回如何配对？** (STEP-fwd/bwd) 的 ∀后继-∃后继：`s₀` 的每个 `⇒^ℓ` 后继都必须有 `s₁` 的 `⇒^ℓ` 后继与之 `I_k` 相关，反之亦然。这是**关系全匹配**，保证 `Tr_T` 集合相等而非单向包含。

**Q5 一边终止、另一边继续怎么办？** (OBS) 要求 `Term(s₀)=Term(s₁)`。`DONE vs RUN/STUCK`、`DONE vs STUCK` 都使 `I_k` 不成立 ⇒ 证书无法通过，正确拒绝。一边在 `k` 步内终止、另一边终止但 `τ` 数不同 ⇒ `obs` 的 `visibleTrace` 与 `Term` 均相同，允许（`(TAU)` 吸收 `τ`）。

## 6. 三个层次必须区分（任务包 D6 要求）

| 层次 | 研究对象 | 结论 |
| --- | --- | --- |
| **Trace equivalence** | 两边可观察轨迹集合 `Tr_T` 相等 | **目标性质 `C_T`** |
| **Bounded weak bisimulation** | `I_k` 关系族满足 (OBS)+(BASE)+(TAU)+(STEP)+(INIT) | **更强的充分条件**；`I_k ⇒ C_T`，反向不成立（见 `SOUNDNESS_PROOF.md` §4） |
| **SNARK certificate** | 隐藏 `I_k`（及可选模型细节），公开验证条件成立 | **密码学实现层**；不改变上述数学强弱关系 |

**明确的回答（`[数学推导]`）**：
1. **`I_k` 是否仅是 bounded bisimulation？** 是——准确说是**带观察一致性约束的有界弱互模拟**（bounded weak bisimulation with observation labels）。`k` 限制可观察步数，不限制 `τ` 数。
2. **是否足以证明目标 bounded NI？** 是，`I_k ⇒ C_T`（完整证明见 `SOUNDNESS_PROOF.md` §2–3）。
3. **是否对所有 bounded NI 模型完备？** **否**。§4 与 `SOUNDNESS_PROOF.md` §4 给出 trace-equivalent but not bisimilar 的具体反例。
4. **是否存在其他关系证书补足？** 开放问题。可考虑集合级关系（set-based bisimulation）、trace 自动机状态、或显式 trace 枚举，但**本轮不主张任何复杂度下界**（见 `ERRATA.md`）。
5. **SNARK 隐藏了什么？** 若 `I_k` 与转移关系 `→` 都作为见证提交，验证者只见承诺与约束结果，则隐藏的是**关系证明本身**与**模型细节**；但：(a) 验证条件中的 ∀后继检查要求验证者能以某种方式访问转移结构（承诺 + 查找论证或公开模板），隐藏并非免费；(b) 即使模型隐藏，也**不解决模型来源信任**——验证者只能相信"某个被承诺模型满足条件"，无法确认它就是实际 Agent 的忠实抽象（`[待验证]`，对应 Phase 1C 停止条件 5）。

## 7. 证书规模与表示（`[数学推导]`，细节见冻结文档 `COMPLEXITY_COMPARISON.md`）

证书需要给出：
1. 每个 `I_k` 的表示：显式集合 `O(|S|²·T)`，或判定电路/决策表；
2. 对每个 `(s₀,s₁,k,ℓ)` 的匹配见证：后继配对函数 `f : Succ_ℓ(s₀) → Succ_ℓ(s₁)` 及逆配对（满足 (STEP-fwd/bwd)），以及对 `τ` 的 `⇒^ε` 路径证据。

**紧凑性唯一来源**：若 `I_k` 有简洁语义描述（例如"`I_k ⟺ Obs 相等 ∧ Term 相等 ∧ m_H 任意`"，与 `k` 无关），则证书规模与 `|S|²` 解耦，Step 检查按结构做而非逐状态枚举。若必须显式列出 `|S|²·T` 项，则相对枚举 `|X_H|²` 对未必有优势。

**本轮撤回**：旧 `SOUNDNESS_PROOF.md` §4.3 "紧凑 I 与完备 I 不可兼得"的**普遍断言**。本轮不提供正式复杂度假设/归约/下界，故该命题降级为**待研究假设**（`[待验证]`），只在"关系形式受限"的具体语境下可作经验观察。冻结文档 `COMPLEXITY_COMPARISON.md` §5 与 `DECISION.md` 中的同类断言因范围冻结不修改，仅在 `phase1d1/ERRATA.md` 记录。

## 8. 小结

- 旧 `Sync` 撤回；内部动作统一为 `τ`，用弱转移 `⇒^ℓ` 吸收不等的 `τ` 步数；
- 证书是有界关系族 `I₀..I_T`，`k` 为剩余可观察预算；(OBS) 对所有 k 成立，(BASE) 仅 k=0；
- (TAU) 处理内部步（不消耗预算），(STEP) 双向 ∀后继-∃后继处理可观察步，(INIT) 对 `X_H` 全称；
- `I_k` 是 bounded weak bisimulation 的充分证书，证明 `C_T` 但不完备；
- SNARK 隐藏关系与可选模型细节，但不解决模型真实性信任。
