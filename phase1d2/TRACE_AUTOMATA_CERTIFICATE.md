## 1. 把有限 Agent 模型映射为观察轨迹自动机

给定 `M=(S,Λ,→,Init,Obs,Term,X_L,X_H,T)` 与固定的 `(x_L,h)`，构造**分层观察轨迹 NFA**。第二坐标记录已消耗的可观察动作数，据此把 `T` 上界真正编码进状态结构（Phase 1D.2.1 修正）：

```
A_T(x_L,h) = (Q_T, Λ̂, Δ_T, q₀, F)
Q_T  = (S × {0,1,…,T}) ⊎ { q_acc }        （有限，|Q_T| = |S|·(T+1)+1）
Λ̂    = Λ ⊎ {⊢RUN, ⊢DONE, ⊢STUCK}         （可观察标签 + 终止标记）
q₀   = (Init(x_L,h), 0)
F    = { q_acc }
Δ_T  = Δ_vis ∪ Δ_τ ∪ Δ_term, 其中：
   Δ_vis  : ((s,i), ℓ, (s',i+1))   对每个 ℓ∈Λ, i∈{0,…,T-1}, 且 s —ℓ→ s'
   Δ_τ    : ((s,i), ε, (s',i))     对每个 s —τ→ s', 每个 i∈{0,…,T}
   Δ_term : ((s,i), ⊢t, q_acc)     对每个 Term(s)=t, 每个 i∈{0,…,T}
```

**分层语义**（`[定义]`）：
- `τ` 折叠为 `ε` 边且**计数不变**（内部动作不计入 `T`）；NFA 的 ε-路径原生表达"两侧内部步数不同"。
- 可观察动作 `ℓ∈Λ` 使计数 `i→i+1`，且仅当 `i<T` 时可用 ⇒ 任何接受路径最多含 `T` 个可观察标签。
- 终止标记 `⊢t` 只从计数 `i≤T` 的状态发出，进入唯一接受态 `q_acc`；`DONE/STUCK/RUN` 编码为字母，与 `PROPERTY_REFINEMENT.md` §1 的 `Λ̂` 完全一致。
- **计数不变量**（`[数学推导]`）：自动机到达 `(s,i)` 时恰好读入 `i` 个 `Λ` 标签——初始 `i=0`；`Δ_vis` 读一标签且计数 `+1`；`Δ_τ` 不读标签且计数不变。

**关键命题**（`[数学推导]`）：
```
L( A_T(x_L,h) ) = L_T(M, x_L, h)
```
其中 `L_T(M,x_L,h) = { w·⊢t ∈ Λ̂* | ∃π from Init(x_L,h): visibleTrace(π)=w, Term(last(π))=t, |w|≤T }`（`PROPERTY_REFINEMENT.md` §1，已含 `|w|≤T`）。

**证明（双向包含）**：

**(⊆)** 设 `w·⊢t` 被 `A_T` 接受，取一条接受路径。因 `q_acc` 无出边且 `F={q_acc}`，`⊢t` 必为路径最后一个标签，且只能经 `Δ_term` 边 `((s,i),⊢t,q_acc)` 进入。由计数不变量，进入该边前已读入 `i` 个 `Λ` 标签，故 `|w|=i`；又 `Δ_vis` 只在 `i<T` 时递增、`Δ_term` 只在 `i≤T` 时发出，得 `|w|=i≤T`。把路径逐边投影回 `M`：`Δ_vis` 边 `((s,i),ℓ,(s',i+1))` 对应 `s—ℓ→s'`，`Δ_τ` 边 `((s,i),ε,(s',i))` 对应 `s—τ→s'`（均按 `Δ_T` 定义），拼接得从 `Init(x_L,h)` 到 `s` 的执行 `π`，`visibleTrace(π)=w`；`Δ_term` 边来自 `Term(s)=t`，故 `obs(π)=(w,t)` 且 `|w|≤T`，即 `w·⊢t∈L_T`。

**(⊇)** 设 `w·⊢t∈L_T`，取执行 `π=s₀—a₁→…—a_n→s_n`，`s₀=Init(x_L,h)`，`visibleTrace(π)=w=ℓ₁…ℓ_m`，`Term(s_n)=t`，`m≤T`。令 `cnt(j)` 为 `π` 前 `j` 个转移中可观察转移数（`cnt(0)=0,cnt(n)=m`）：若 `a_{j+1}=τ` 则 `cnt(j+1)=cnt(j)`；若 `a_{j+1}=ℓ∈Λ` 则 `cnt(j+1)=cnt(j)+1≤m≤T`。构造自动机路径：对每 `j` 取 `(s_j,cnt(j))`（各 `cnt(j)≤T`，合法）。`τ` 转移对应 `Δ_τ` 边 `((s_j,cnt(j)),ε,(s_{j+1},cnt(j+1)))`；可观察转移 `a_{j+1}=ℓ` 时 `cnt(j)<T`，对应 `Δ_vis` 边 `((s_j,cnt(j)),ℓ,(s_{j+1},cnt(j)+1))`。该路径从 `q₀=(Init(x_L,h),0)` 到 `(s_n,m)`，删 ε 后标签为 `w`；再由 `Term(s_n)=t` 取 `Δ_term` 边 `((s_n,m),⊢t,q_acc)` 到接受态。故 `w·⊢t∈L(A_T)`。∎

于是 bounded NI 化为自动机语言等价：

```
C_T(M)  ⟺  ∀x_L,h₀,h₁ :  L( A_T(x_L,h₀) ) = L( A_T(x_L,h₁) )        [数学推导]
```

## 2. NFA、DFA、有限深度自动机的差异

| 形式 | 表示 | 非确定性 | 语言等价判定 | 规模上界 |
| --- | --- | --- | --- | --- |
| **分层 NFA**（§1 的 `A_T`） | `Δ_T: Q_T×Λ̂→𝒫(Q_T)` | 原生 | 一般 NFA 等价 PSPACE-complete `[标准结论]`；本分层特例的复杂度未单独证明 `[待验证]` | `O(\|S\|·(T+1))` 状态（计入计数层） |
| **DFA** | `Δ: Q×Λ̂→Q` | 无（需子集构造确定化） | P（乘积可达 / Hopcroft 最小化 `O(\|Σ\|n log n)`）`[标准结论]` | 最坏 `2^{\|S\|(T+1)}` 状态 |
| **有限深度自动机**（深度 ≤T 的 trie/DAG） | 分层 DAG | 视构造而定 | 逐层比较 | 叶数最坏 `\|Λ̂\|^T` |

**要点**（`[数学推导]`）：
- 模型 `M` 的非确定性（工具多返回、LLM 抽象）由 NFA 原生表达，无需在建模阶段消除；
- **分层计数层不是免费的**：为把 `T` 上界纳入自动机结构，状态从 `O(|S|)` 增至 `O(|S|·(T+1))`，DFA 确定化上界相应从 `2^{|S|}` 增至 `2^{|S|(T+1)}`；这是修正 `L(A)=L_T` 漏洞的必要代价；
- DFA 确定化需**子集构造**，最坏指数，但换来多项式时间等价判定；
- 有限深度自动机把有界性 `T` 直接编码进结构，避免了无限语言的一般算法，但叶数随 `T` 指数；
- 三种表示是**同一语言 `L_T` 的三种编码**，不存在"哪个更本质"——选择取决于"证书规模"与"验证复杂度"的权衡（见 `COMPARISON_MATRIX.md`）。

## 3. 如何验证两个自动机的有界语言相等（`[数学推导]` + `[标准结论]`）

1. **NFA 路线**：判定 `L(A_T⁰)=L(A_T¹)` 需双向包含；一般 NFA 包含/等价是 PSPACE-complete（标准结论，本轮原文页面被反爬拦截，按教科书定理记录，`[标准结论]`）。**收紧**：PSPACE-completeness **不等于**已证明"不存在多项式大小、可多项式时间验证的正向证书"——若存在此类证书则该问题属于 NP，结合 PSPACE-completeness 将推出 `PSPACE=NP`；这是基于复杂度类分离假设的推论，不是已证明的证书大小下界（`[数学推导]`）。本分层 NFA 是"有界观察深度"特例，其等价判定复杂度未单独证明（`[待验证]`）。
2. **DFA 路线**：
   - 子集构造把 `A_T⁰,A_T¹` 确定化；
   - 乘积自动机 `A_T⁰×A_T¹`（状态数 `|Q₀|·|Q₁|`，`Qᵢ` 为确定化后状态集），从初态做可达性搜索，寻找"一侧接受、另一侧拒绝"的状态 ⇒ 不等价；无此状态 ⇒ 等价（普通验证层；电路层需闭包证书，见 §6）；
   - 或各自最小化后比较同构。
3. **有限深度路线**：把两棵深度 ≤T 的 trie（或 DAG）按层比较叶集/转移集；复杂度与叶数同阶。

**是否必须进行子集构造？** 否——一般 NFA 等价可用按需子集搜索（implicit subset construction）在 PSPACE 内判定，不必显式构造全部 `2^{N_T}` 状态（这里 `N_T=|S|(T+1)+1`）。"按需"只节省平均情形；但**不写"最坏指数不可避免"作为已证下界**——该判断依赖 `PSPACE≠NP` 等复杂度类分离假设（见 §3 第 1 点），按 `[待验证]` 处理。

## 4. 反例的实际分析：自动机如何表达相同语言（`[反例]` + `[数学推导]`）

复述反例（§2.3 of `STATE_RELATION_CERTIFICATE.md`）：左侧 `s —a→ {a₁,a₂}`，`a₁—b→DONE`，`a₂—c→DONE`；右侧 `t —a→ u`，`u —b→DONE`，`u —c→DONE`。互模拟失败，但自动机证书**应当成功**。本轮实际构造。

**记号约定（1D.2.1）**：以下转移表是 §1 分层 NFA `A_T` 在 `T≥2` 时**省略第二坐标**的简写。所有接受路径的观察长度均为 2，计数层依次为 `0→1→2`（由 §1 计数不变量唯一确定），故把 `(s,0),(a₁,1),(b₁,2)` 投影为 `s,a₁,b₁` 不改变子集构造的同构结论；终止标记 `⊢DONE` 从计数 2 的状态发出，满足 `Δ_term` 的 `i≤T` 约束。

### 4.1 左侧 NFA `A₀`（含终止标记）

```
Q = {s, a₁, a₂, b₁, c₁, q_acc}
Δ:
  s   —a→   {a₁, a₂}          ← 非确定性：一个 a 边到两个后继
  a₁  —b→   {b₁}
  a₂  —c→   {c₁}
  b₁  —⊢DONE→ {q_acc}
  c₁  —⊢DONE→ {q_acc}
接受串：a·b·⊢DONE, a·c·⊢DONE
```

### 4.2 右侧 NFA `A₁`

```
Q = {t, u, b₂, c₂, q_acc}
Δ:
  t —a→ {u}
  u —b→ {b₂},  u —c→ {c₂}     ← 一个状态两个出边
  b₂ —⊢DONE→ {q_acc}
  c₂ —⊢DONE→ {q_acc}
接受串：a·b·⊢DONE, a·c·⊢DONE
```

### 4.3 子集构造：为什么 DFA 化后两者相同（`[数学推导]`）

对左侧做子集构造（ε 闭包为空，省略）：

| DFA 状态（NFA 状态集） | `a` | `b` | `c` | `⊢DONE` |
| --- | --- | --- | --- | --- |
| `{s}`（初态） | `{a₁,a₂}` | ∅ | ∅ | ∅ |
| `{a₁,a₂}` | ∅ | `{b₁}` | `{c₁}` | ∅ |
| `{b₁}` | ∅ | ∅ | ∅ | `{q_acc}` |
| `{c₁}` | ∅ | ∅ | ∅ | `{q_acc}` |
| `{q_acc}`（接受） | ∅ | ∅ | ∅ | ∅ |

对右侧做子集构造：

| DFA 状态（NFA 状态集） | `a` | `b` | `c` | `⊢DONE` |
| --- | --- | --- | --- | --- |
| `{t}`（初态） | `{u}` | ∅ | ∅ | ∅ |
| `{u}` | ∅ | `{b₂}` | `{c₂}` | ∅ |
| `{b₂}` | ∅ | ∅ | ∅ | `{q_acc}` |
| `{c₂}` | ∅ | ∅ | ∅ | `{q_acc}` |
| `{q_acc}`（接受） | ∅ | ∅ | ∅ | ∅ |

**观察**：把左侧的 `{s}↔{t}`、`{a₁,a₂}↔{u}`、`{b₁}↔{b₂}`、`{c₁}↔{c₂}` 重命名后，两张 DFA 转移表**逐项相同**。左侧的"两个 a 后继"在 DFA 中被**合并**成一个宏状态 `{a₁,a₂}`，其出边集合 `{b,c}` 恰与右侧单状态 `u` 的出边集合 `{b,c}` 一致。

⇒ 最小化后得到同一个 4 状态 DFA ⇒ `L(A_T⁰)=L(A_T¹)` ⇒ 自动机证书**成功识别**该 trace-equivalent 对（此处 `T≥2`，§1 的计数层已按记号约定省略）。

### 4.4 与互模拟失败原因的对照（`[数学推导]`）

- 互模拟在**原状态粒度**要求 `a₁` 与 `u` 匹配（`a₁` 只有 `b`，`u` 有 `b,c`）⇒ 失败。
- 自动机证书在**幂集状态粒度**比较 `{a₁,a₂}` 与 `u`（出边均 `{b,c}`）⇒ 成功。
- **差别正是子集构造的"合并"能力**：它把"多个状态分担不同标签"压成"一个宏状态承担并集标签"，这是从状态结构到语言结构的跃迁。

## 5. 证书规模与指数风险（`[数学推导]`）

- NFA 证书（`A_T`）：状态 `O(|S|·(T+1))`，转移 `O(|S|·(T+1)·|Λ̂|)`；一般 NFA 等价判定 PSPACE-complete，但对证书大小的推论需按 §3 第 1 点收紧，不写成已证下界。
- DFA 证书：最坏 `2^{|S|(T+1)}` 状态；本例中左侧只产生 5 个可达子集（分层后仍远小于上界），说明**实际可达子集数常远小于上界**，但不是普遍保证。
- 有限深度证书：深度 `T` 的 trie 叶数 `≤ |Λ̂|^T`；`T` 小（如 Phase 1B 的 cap=50 是图节点数，非观察深度）时可控，但 `T` 线性增长即指数爆炸。

**不写普遍下界**：本轮不主张"自动机证书必然指数/必然优于互模拟"，只记录**本构造在此表示下的规模事实**与标准复杂度结论（PSPACE-complete / P）。

## 6. 隐藏模型与 ZK 的接口（`[待验证]`）

- 若要在 ZK 中验证自动机语言等价：需把 `A_T⁰,A_T¹` 的转移表（或承诺）编码进电路；**DFA 电路成本目前只是估算，不是已证明的约束规模**——普通乘积可达性只给出"存在到达不一致状态的路径"的判定，而电路中要证明"**不存在**这样的路径"，需额外给出可验证的闭包/不变式证书（例如可达集上界 `R`：初态∈`R`、`R` 对乘积转移封闭、`R` 中无不一致状态），电路验证该不变式而非枚举指数多条路径；`R` 本身最坏仍达 `|Q₀|·|Q₁|`，故"电路便宜"没有保证（`[待验证]`）。NFA 路线的 PSPACE 算法难以直接算术化（`[待验证]`）。
- 隐藏 `A_T⁰,A_T¹` 的转移结构 ⇒ 验证者看不到模型；但**必须公开**初态、字母表、`T`、以及"两个自动机来自同一被承诺模型 `C_M`"的绑定关系。
- 电路成本 ≠ 普通算法复杂度：普通 DFA 等价是 P，但电路中逐状态检查仍需为每个状态分配约束；不可把"普通多项式"直接等同于"SNARK 便宜"。详见 `COMPARISON_MATRIX.md`、`ZK_VALUE_ANALYSIS.md`。

## 7. 小结

1. **分层**观察轨迹自动机 `A_T(x_L,h)` 的接受语言恰为 `L_T(M,x_L,h)`（§1 已给出双向包含证明），把 `C_T` 化为自动机语言等价；`T` 上界已编码进状态第二坐标，规模 `O(|S|·(T+1))`。
2. NFA 原生表达非确定性与 τ；DFA 需子集构造但等价判定多项式（最坏 `2^{|S|(T+1)}` 状态）；有限深度自动机把 `T` 编入结构但叶数指数。
3. **反例已被实际分析**：子集构造把左侧 `{a₁,a₂}` 合并，与右侧 `u` 出边同为 `{b,c}`，最小化后同一 DFA ⇒ 自动机证书成功，互模拟失败。这是"合并"能力带来的完备性提升。
4. 规模风险真实但不写普遍下界（PSPACE-completeness 不推出证书大小下界，见 §3）；DFA 电路成本标为**估算**并需闭包/不变式证书，不能等同于普通复杂度（见 §6）。
