## 1. 把有限 Agent 模型映射为观察轨迹自动机

给定 `M=(S,Λ,→,Init,Obs,Term,X_L,X_H,T)` 与固定的 `(x_L,h)`，构造**观察轨迹 NFA**：

```
A(x_L,h) = (Q, Λ̂, Δ, q₀, F)
Q    = S ⊎ { q_accept }                       （有限，|Q| ≤ |S|+1）
Λ̂   = Λ ⊎ {⊢RUN, ⊢DONE, ⊢STUCK}             （可观察标签 + 终止标记）
q₀   = Init(x_L,h)
F    = { q_accept }
Δ    = Δ_vis ∪ Δ_τ ∪ Δ_term, 其中：
   Δ_vis  : (s, ℓ, s')      对每个 ℓ∈Λ 且 s —ℓ→ s'
   Δ_τ    : (s, ε, s')      对每个 s —τ→ s'          （内部动作作 ε 边）
   Δ_term : (s, ⊢t, q_accept)  对每个 Term(s)=t
```

**终止与内部动作的处理**（`[定义]`）：
- `τ` 折叠为 `ε` 边 ⇒ 自动机原生表达"两侧内部步数不同"（NFA 的 ε-路径）。
- `DONE/STUCK/RUN` 编码为**终止标记字母** `⊢t`，进入接受态 `q_accept`；这与 `PROPERTY_REFINEMENT.md` §1 的 `Λ̂` 完全一致。
- `RUN` 用于 `≤T` 步内未终止的状态；`T` 通过**只接受长度 ≤ T+1**（T 个可观察标签 + 1 个终止标记）来强制，即把 `A` 与长度上界自动机相乘，或限定证明只覆盖深度 ≤T 的接受路径。

**关键命题**（`[数学推导]`）：
```
L( A(x_L,h) ) = L_T(M, x_L, h)
```
即自动机接受语言恰是 Phase 1D.2 的统一观察语言。证明：NFA 路径的标签序列 = `visibleTrace(π)·⊢t`，终止标记只在 `Term(s)=t` 的状态发出，与 `obs(π)` 定义逐项对应。∎

于是 bounded NI 化为自动机语言等价：

```
C_T(M)  ⟺  ∀x_L,h₀,h₁ :  L( A(x_L,h₀) ) = L( A(x_L,h₁) )        [数学推导]
```

## 2. NFA、DFA、有限深度自动机的差异

| 形式 | 表示 | 非确定性 | 语言等价判定 | 规模上界 |
| --- | --- | --- | --- | --- |
| **NFA** | `Δ: Q×Λ̂→𝒫(Q)` | 原生 | PSPACE-complete `[标准结论]` | `O(\|S\|)` 状态 |
| **DFA** | `Δ: Q×Λ̂→Q` | 无（需子集构造确定化） | P（乘积可达 / Hopcroft 最小化 `O(\|Σ\|n log n)`）`[标准结论]` | 最坏 `2^{\|S\|}` 状态 |
| **有限深度自动机**（深度 ≤T 的 trie/DAG） | 分层 DAG | 视构造而定 | 逐层比较 | 叶数最坏 `\|Λ̂\|^T` |

**要点**（`[数学推导]`）：
- 模型 `M` 的非确定性（工具多返回、LLM 抽象）由 NFA 原生表达，无需在建模阶段消除；
- DFA 确定化需**子集构造**，最坏指数，但换来多项式时间等价判定；
- 有限深度自动机把有界性 `T` 直接编码进结构，避免了无限语言的一般算法，但叶数随 `T` 指数；
- 三种表示是**同一语言的三种编码**，不存在"哪个更本质"——选择取决于"证书规模"与"验证复杂度"的权衡（见 `COMPARISON_MATRIX.md`）。

## 3. 如何验证两个自动机的有界语言相等（`[数学推导]` + `[标准结论]`）

1. **NFA 路线**：判定 `L(A₀)=L(A₁)` 需双向包含；NFA 包含/等价是 PSPACE-complete（标准结论，本轮原文页面被反爬拦截，按教科书定理记录，`[标准结论]`）。
2. **DFA 路线**：
   - 子集构造把 `A₀,A₁` 确定化；
   - 乘积自动机 `A₀×A₁`（状态数 `|Q₀|·|Q₁|`），从初态做可达性搜索，寻找"一侧接受、另一侧拒绝"的状态 ⇒ 不等价；无此状态 ⇒ 等价；
   - 或各自最小化后比较同构。
3. **有限深度路线**：把两棵深度 ≤T 的 trie（或 DAG）按层比较叶集/转移集；复杂度与叶数同阶。

**是否必须进行子集构造？** 否——NFA 等价可在 NFA 上用按需子集搜索（implicit subset construction）在 PSPACE 内判定，不必显式构造全部 `2^{|S|}` 状态。但**最坏情况指数无法避免**（PSPACE-complete 的标准含义）；"按需"只节省平均情形。

## 4. 反例的实际分析：自动机如何表达相同语言（`[反例]` + `[数学推导]`）

复述反例（§2.3 of `STATE_RELATION_CERTIFICATE.md`）：左侧 `s —a→ {a₁,a₂}`，`a₁—b→DONE`，`a₂—c→DONE`；右侧 `t —a→ u`，`u —b→DONE`，`u —c→DONE`。互模拟失败，但自动机证书**应当成功**。本轮实际构造。

### 4.1 左侧 NFA `A₀`（含终止标记）

```
Q = {s, a₁, a₂, b₁, c₁, q_accept}
Δ:
  s   —a→   {a₁, a₂}          ← 非确定性：一个 a 边到两个后继
  a₁  —b→   {b₁}
  a₂  —c→   {c₁}
  b₁  —⊢DONE→ {q_accept}
  c₁  —⊢DONE→ {q_accept}
接受串：a·b·⊢DONE, a·c·⊢DONE
```

### 4.2 右侧 NFA `A₁`

```
Q = {t, u, b₂, c₂, q_accept}
Δ:
  t —a→ {u}
  u —b→ {b₂},  u —c→ {c₂}     ← 一个状态两个出边
  b₂ —⊢DONE→ {q_accept}
  c₂ —⊢DONE→ {q_accept}
接受串：a·b·⊢DONE, a·c·⊢DONE
```

### 4.3 子集构造：为什么 DFA 化后两者相同（`[数学推导]`）

对左侧做子集构造（ε 闭包为空，省略）：

| DFA 状态（NFA 状态集） | `a` | `b` | `c` | `⊢DONE` |
| --- | --- | --- | --- | --- |
| `{s}`（初态） | `{a₁,a₂}` | ∅ | ∅ | ∅ |
| `{a₁,a₂}` | ∅ | `{b₁}` | `{c₁}` | ∅ |
| `{b₁}` | ∅ | ∅ | ∅ | `{q_accept}` |
| `{c₁}` | ∅ | ∅ | ∅ | `{q_accept}` |
| `{q_accept}`（接受） | ∅ | ∅ | ∅ | ∅ |

对右侧做子集构造：

| DFA 状态（NFA 状态集） | `a` | `b` | `c` | `⊢DONE` |
| --- | --- | --- | --- | --- |
| `{t}`（初态） | `{u}` | ∅ | ∅ | ∅ |
| `{u}` | ∅ | `{b₂}` | `{c₂}` | ∅ |
| `{b₂}` | ∅ | ∅ | ∅ | `{q_accept}` |
| `{c₂}` | ∅ | ∅ | ∅ | `{q_accept}` |
| `{q_accept}`（接受） | ∅ | ∅ | ∅ | ∅ |

**观察**：把左侧的 `{s}↔{t}`、`{a₁,a₂}↔{u}`、`{b₁}↔{b₂}`、`{c₁}↔{c₂}` 重命名后，两张 DFA 转移表**逐项相同**。左侧的"两个 a 后继"在 DFA 中被**合并**成一个宏状态 `{a₁,a₂}`，其出边集合 `{b,c}` 恰与右侧单状态 `u` 的出边集合 `{b,c}` 一致。

⇒ 最小化后得到同一个 4 状态 DFA ⇒ `L(A₀)=L(A₁)` ⇒ 自动机证书**成功识别**该 trace-equivalent 对。

### 4.4 与互模拟失败原因的对照（`[数学推导]`）

- 互模拟在**原状态粒度**要求 `a₁` 与 `u` 匹配（`a₁` 只有 `b`，`u` 有 `b,c`）⇒ 失败。
- 自动机证书在**幂集状态粒度**比较 `{a₁,a₂}` 与 `u`（出边均 `{b,c}`）⇒ 成功。
- **差别正是子集构造的"合并"能力**：它把"多个状态分担不同标签"压成"一个宏状态承担并集标签"，这是从状态结构到语言结构的跃迁。

## 5. 证书规模与指数风险（`[数学推导]`）

- NFA 证书：状态 `O(|S|)`，转移 `O(|S|·|Λ̂|)`；但语言等价判定 PSPACE-complete。
- DFA 证书：最坏 `2^{|S|}` 状态；本例中左侧只产生 5 个可达子集（远小于 `2^5=32`），说明**实际可达子集数常远小于上界**，但不是普遍保证。
- 有限深度证书：深度 `T` 的 trie 叶数 `≤ |Λ̂|^T`；`T` 小（如 Phase 1B 的 cap=50 是图节点数，非观察深度）时可控，但 `T` 线性增长即指数爆炸。

**不写普遍下界**：本轮不主张"自动机证书必然指数/必然优于互模拟"，只记录**本构造在此表示下的规模事实**与标准复杂度结论（PSPACE-complete / P）。

## 6. 隐藏模型与 ZK 的接口（`[待验证]`）

- 若要在 ZK 中验证自动机语言等价：需把 `A₀,A₁` 的转移表（或承诺）编码进电路；DFA 路线的乘积可达检查在电路中是 `O(|Q₀||Q₁||Λ̂|)` 约束；NFA 路线的 PSPACE 算法难以直接算术化。
- 隐藏 `A₀,A₁` 的转移结构 ⇒ 验证者看不到模型；但**必须公开**初态、字母表、`T`、以及"两个自动机来自同一被承诺模型 `C_M`"的绑定关系。
- 电路成本 ≠ 普通算法复杂度：普通 DFA 等价是 P，但电路中逐状态检查仍需为每个状态分配约束；不可把"普通多项式"直接等同于"SNARK 便宜"。详见 `COMPARISON_MATRIX.md`、`ZK_VALUE_ANALYSIS.md`。

---

## 7. 小结

1. 观察轨迹自动机 `A(x_L,h)` 的接受语言恰为 `L_T(M,x_L,h)`，把 `C_T` 化为自动机语言等价。
2. NFA 原生表达非确定性与 τ；DFA 需子集构造但等价判定多项式；有限深度自动机把 `T` 编入结构但叶数指数。
3. **反例已被实际分析**：子集构造把左侧 `{a₁,a₂}` 合并，与右侧 `u` 出边同为 `{b,c}`，最小化后同一 DFA ⇒ 自动机证书成功，互模拟失败。这是"合并"能力带来的完备性提升。
4. 规模风险真实但不写普遍下界；ZK 电路成本需单独评估，不能等同于普通复杂度。
