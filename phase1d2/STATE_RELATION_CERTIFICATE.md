# Phase 1D.2 — A：状态关系证书（State-relation certificate）

证据标记：`[定义]`、`[数学推导]`、`[反例]`、`[标准结论]`、`[待验证]`。

---

## 1. 证书对象回顾

状态关系证书是有界关系族 `I₀,…,I_T ⊆ S×S`，满足 (OBS)+(BASE)+(TAU)+(STEP)+(INIT)（见 `PROPERTY_REFINEMENT.md` §2 修正后的定义）。它证明的命题是：

```
(INIT) ∧ (OBS/BASE/TAU/STEP)  ⇒  C_T : ∀x_L,h₀,h₁ : L_T(M,x_L,h₀) = L_T(M,x_L,h₁)
```

**数学身份**（Phase 1D.1 结论，仍成立）：`I_k` 是**带观察一致约束的有界弱互模拟**（bounded weak bisimulation with observation labels）。它是标准互模拟理论的一个有界、带标签变体，不是新原语。

---

## 2. 能否处理所有 trace-equivalent 系统？

**不能。** 这是 Phase 1D.1 反例的直接结论，本轮重新分析其根因。

### 2.1 反例（复述，`[反例]`）

无 τ，字母表 `Λ={a,b,c}`，终止标记 `⊢DONE`。

**左侧系统（h₀）**：
```
s  —a→ a₁ ,  s —a→ a₂
a₁ —b→ b₁(DONE)          a₂ —c→ c₁(DONE)
```

**右侧系统（h₁）**：
```
t  —a→ u
u  —b→ b₂(DONE) ,  u —c→ c₂(DONE)
```

**观察语言**：
```
L_T(M,x_L,h₀) = { a·b·⊢DONE, a·c·⊢DONE }
L_T(M,x_L,h₁) = { a·b·⊢DONE, a·c·⊢DONE }
⇒ 相等，C_T 成立
```

### 2.2 为什么互模拟证书失败（`[数学推导]`）

(INIT) 强制 `I₂(s,t)`。逐步推演：

1. `s —a→ a₁` ⇒ (STEP-fwd) 要求 `∃ t' : t —a→ t' ∧ I₁(a₁,t')`。`t` 的唯一 `a`-后继是 `u` ⇒ **`I₁(a₁,u)` 必须成立**。
2. `s —a→ a₂` ⇒ 同理 **`I₁(a₂,u)` 必须成立**。
3. 考察 `I₁(a₁,u)`：`u —c→ c₂`。由 (STEP-bwd) 于 `I₁(a₁,u)` 与 `u —c→ c₂`，要求 `∃ s' : a₁ —c→ s'`。但 `a₁` **没有** `c`-后继 ⇒ 矛盾。
4. 对称考察 `I₁(a₂,u)` 与 `u —b→ b₂` 同样矛盾。

⇒ 不存在满足条件的 `I₀..I_T`。

### 2.3 根因：逐状态匹配 vs 逐语言匹配（`[数学推导]`）

失败的根因**不是** `I_k` 的形式写得不好，而是**互模拟的匹配粒度是单个状态**：

- 左侧在 `a` 之后有**两个**后继状态 `a₁`（只给 `b`）、`a₂`（只给 `c`）；
- 右侧在 `a` 之后有**一个**后继状态 `u`（同时给 `b` 和 `c`）；
- 互模拟要求每个左侧后继都找到右侧**单一状态**匹配，并反过来。于是 `a₁` 被迫匹配 `u`，但 `u` 的 `c` 边无处可去。
- 语言等价只要求**可观察轨迹集合**相等：`{ab,ac}` 在两侧相同。它不要求"给出 `b` 的状态"与"给出 `c` 的状态"是同一个状态。

**结论**：互模拟对 `C_T` 是**真充分非必要**。不可比较的不是 A/C，而是"互模拟可证" ⊂ "trace 等价" 真包含。

## 3. 能否通过改变关系对象或增加辅助信息解决？

### 3.1 改变关系对象：从"状态对"到"状态↔状态集合"（`[数学推导]`）

允许 `I_k ⊆ S × 𝒫(S)`（一侧单状态、另一侧后继集合），把匹配改为：

```
I₁(a₁, {u}) 与 I₁(a₂, {u})  ⇒  把 {a₁,a₂} 的并行为 {b}∪{c} 与 {u} 的 {b,c} 比较
```

这正是**幂集构造（powerset construction）**的雏形：把左侧 `{a₁,a₂}` 视作一个"宏状态"，其出边是 `b,c`，与 `u` 的出边 `b,c` 一致。改进后的"集合级互模拟"可以证明该反例。

**代价**（`[数学推导]`）：
- 关系对象从 `S×S`（`O(|S|²)`）膨胀到 `S×𝒫(S)`（`O(|S|·2^{|S|})`）；
- 这已经**不是**简单的状态关系证书，而是把轨迹自动机的子集构造搬进了证书（见 `TRACE_AUTOMATA_CERTIFICATE.md`）；
- 复杂度最坏指数，回到显式枚举规模——但**这不是**"紧凑与完备不可兼得"的普遍下界，只是"本构造在此表示下的规模事实"。

### 3.2 增加辅助信息：`[待验证]`

可能的辅助方向（本轮不验证其充分性/复杂度）：
1. **后继集合签名**：让 `I_k(s₀,s₁)` 携带"剩余可观察语言 `L^{(k)}(s)` 的摘要"，把逐状态匹配升级为逐语言摘要匹配。摘要如何计算/比较本身需要子证书。
2. **分区细化反向**：从 trace 集合反推最大等价分区（自动机最小化），再验证分区是互模拟——但反例中最大 trace 等价分区恰好不是互模拟分区，此路不通。
3. **多个不变量析取**：`I = ⋃_j I^j`，允许不同后继用不同不变量配对——但 `I₁(a₁,u)` 的矛盾来自"u 有 c 而 a₁ 没有"，析取也无法消除单个状态对的边集差异。

### 3.3 能否证明所有 trace-equivalent 系统？（`[数学推导]`）

若把状态关系放宽到"状态对的剩余语言相等" `I(s₀,s₁) ⟺ L^{(k)}(s₀)=L^{(k)}(s₁)`，则由定义它对**所有** trace-equivalent 系统成立——但此时 `I` 的判定本身等价于语言等价问题（NFA 等价 PSPACE-complete，`[标准结论]`），证书收缩为"把原问题重述一遍"，没有提供独立可验证的结构。**这是循环，不是证书。**

## 4. 是否只是把标准 bisimulation 重新包装？

**是，而且必须诚实承认**（`[数学推导]`）：

| 成分 | 标准理论中的对应 | Phase 1D.1 增加的部分 |
| --- | --- | --- |
| `I ⊆ S×S` | 互模拟关系 | 无 |
| 双向 ∀∃ 转移匹配 | 弱互模拟定义 | 无 |
| `⇒^ℓ` 吸收 `τ*` | Milner 弱转移 | 无 |
| `k` 索引 | —— | 有界步数索引（标准有界展开） |
| (OBS) `Obs/Term` 一致 | 带标签互模拟 | 观察标签绑定 |
| (INIT) 全称 `X_H` | —— | 为套用 NI 全称量词而加 |
| ZK 隐藏 `I`/`→` | —— | 密码学封装层 |

**新增内容的性质**：`k` 索引与 (INIT) 是**应用层的书写适配**（把互模拟套到 bounded NI 的量词形态上），不是新的可证性质；ZK 隐藏是**实现层**。因此状态关系证书的数学贡献 = 标准有界弱互模拟，无密码学新原语。

**不可写成创新点**：Phase 1D `DECISION.md` 已按此诚实承认；本轮维持。

---

## 5. 隐瞒/公开边界（`[数学推导]`）

- 若 `I_k` 与 `→` 都隐藏：验证者只见承诺，需电路检查 ∀∃ 转移匹配 ⇒ 必须把转移结构以可验证形式编码（承诺 + 查找论证或公开模板）。
- 若 `I_k` 公开、`→` 隐藏：验证者可检查关系结构，但仍需访问转移以验证匹配条件。
- 若两者都公开：普通互模拟检查（多项式）即可，ZK 无增益。
- 三种情况下**模型真实性都不在证明内**：证明的是"被承诺/被检查模型满足 bounded NI"，不是"真实 Agent 满足"。

---

## 6. 小结

1. 状态关系证书 = 有界弱互模拟，**充分非必要**。
2. 反例失败的根因是**逐状态匹配**：左侧 `a` 后两状态、右侧 `a` 后一状态，互模拟强迫逐对匹配导致边集矛盾；语言等价只比较轨迹集合。
3. 改为"状态↔集合"可补救，但等价于把幂集构造搬进证书，规模最坏指数，**不是**普遍下界。
4. 数学内核是标准互模拟，ZK 只是封装层；隐瞒模型不解决模型真实性。
5. 下一节考察直接用自动机语言等价作为证书，看它是否既完备又可控。
