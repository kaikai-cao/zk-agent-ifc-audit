## 1. 统一观察语言表述（`[定义]`）

沿用有限 LTS `M = (S, Λ, →, Init, Obs, Term, X_L, X_H, T)` 与弱转移 `⇒^ℓ`。对具体执行 `π`：

```
visibleTrace(π) = delete_τ(a₁,…,a_n) ∈ Λ*
obs(π)          = ( visibleTrace(π), Term(last(π)) )
Tr_k(s)         = { obs(π) | π 从 s 出发, |visibleTrace(π)| ≤ k }
```

把 `Term` 的第二分量编码为终止标记字母：`Λ̂ = Λ ⊎ {⊢RUN, ⊢DONE, ⊢STUCK}`。则**有界观察语言**：

```
L_T(M, x_L, h) = { w · ⊢t ∈ Λ̂*  |
                    ∃π from Init(x_L,h): visibleTrace(π)=w, Term(last(π))=t, |w| ≤ T }
```

于是 Phase 1D.1 的 bounded NI 等价于：

```
C_T(M)  ⟺  ∀x_L∈X_L, ∀h₀,h₁∈X_H :  L_T(M,x_L,h₀) = L_T(M,x_L,h₁)      [数学推导]
```

`Tr_k(s) = Tr_k(s')` 与 `L_T(M,x_L,h₀)=L_T(M,x_L,h₁)` 是同一集合的两种记法。这一等价是三种证书对象可比的前提：

| 证书对象 | 证明的命题 | 与 `C_T` 的关系 |
| --- | --- | --- |
| 状态关系 `I_k` | 存在满足约束的二元关系 | `⇒ C_T`（充分，非必要） |
| 轨迹自动机 `A₀,A₁` | `L(A₀)=L(A₁)`（自动机语言等价） | `⇔ C_T`（若自动机忠实于 M） |
| 有限观察语言 `L₀,L₁` | 集合相等 `L₀=L₁` | `⇔ C_T`（定义本身） |

**关键区分**：`C_T` 是目标性质；三种证书是**证明该性质的不同证据结构**，不是三个不同性质。

## 2. 遗留修正 L1：STEP 定义遗漏（`[修正记录]`）

**问题**：基线 `phase1d/INDUCTIVE_CERTIFICATE.md` §3.4 的正式定义块写作

```
(STEP-fwd) ∀ℓ∈Λ, ∀s₀' : s₀ ⇒^ℓ s₀' ⇒ ∃ s₁' : s₁ ⇒^ℓ s₁' ∧ I_k(s₀',s₁')
```

遗漏了前提 `I_{k+1}(s₀,s₁)`。若按字面读，它要求**任意**状态对 `(s₀,s₁)` 都满足匹配，这与 §4 汇总、`SOUNDNESS_PROOF.md` 引理 2（`I_{k+1}(s₀,s₁) ∧ s₀⇒^ℓ s₀' ⇒ ∃s₁': s₁⇒^ℓ s₁' ∧ I_k`）不一致。

**修正**：正式块补入 `I_{k+1}(s₀,s₁) ∧`，并把 `k` 显式限定为 `[0,T-1]`：

```
(STEP-fwd) ∀k∈[0,T-1], ∀s₀,s₁,ℓ,s₀' :
              I_{k+1}(s₀,s₁) ∧ (s₀ ⇒^ℓ s₀') ⇒ ∃ s₁' : (s₁ ⇒^ℓ s₁') ∧ I_k(s₀',s₁')
(STEP-bwd) 对称
```

**一致性核对**（本轮执行）：
- `SOUNDNESS_PROOF.md` 引理 2 陈述为 `I_{k+1}(s₀,s₁) ∧ s₀⇒^ℓ s₀' ⇒ ∃s₁': s₁⇒^ℓ s₁' ∧ I_k(s₀',s₁')` —— 与修正后定义**一致**。
- 引理 3 步骤 2 在 `I_k(v,u)` 上以 `k≥1` 消耗一步得 `I_{k-1}(w,u')`，是 `(j+1)→j` 实例化于 `j=k-1` —— 与修正后定义**一致**。
- §4 汇总块本来就含 `I_{k+1}(s₀,s₁) ∧` —— 与修正后定义**一致**。
- **结论**：修正只涉及 §3.4 正式块的文字完整性；SOUNDNESS_PROOF 的证明结构无需改动，定理 1 结论不变。

## 4. 本轮三个证书对象的判定口径

- **状态关系证书**：回答"它是否只是标准 bisimulation 的重新包装"——是；但需精确说明它在哪类系统上失败、失败的根因是"逐状态匹配"而非"逐语言匹配"。
- **轨迹自动机证书**：必须实际展示自动机如何表达反例中的相同语言（子集构造把 `{a₁,a₂}` 合并为一个 DFA 状态），而不是只说"DFA 可以处理"。
- **有限语言证书**：必须以 `L_T` 为直接对象，分析 trie/DAG/最小自动机表示，且**不**因"有限可枚举"就默认可扩展。
