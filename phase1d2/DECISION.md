**本轮最终状态：PASS**（执行层验收通过；裁决层为 STOP，二者不矛盾——见 §5）。

## 1. 对三种证书对象的判定

| 对象 | 判定 | 依据 |
| --- | --- | --- |
| State relation (`I_k`) | 标准 bounded weak bisimulation，充分非必要；重包装 | `STATE_RELATION_CERTIFICATE.md` §2–4 |
| Trace automata | 标准 NFA/DFA 语言等价；子集构造合并且完备；内核标准 | `TRACE_AUTOMATA_CERTIFICATE.md` §4；反例已实际分析 |

**关键发现**：自动机证书确实比互模拟更接近 `C_T`——子集构造把左侧 `{a₁,a₂}` 合并成宏状态，与右侧 `u` 出边同为 `{b,c}`，最小化后同一 DFA ⇒ 成功识别反例中的 trace-equivalent 对。但这一提升来自**经典子集构造**，不是新理论；一旦要 ZK 化，就回到"DFA 等价电路 + 承诺绑定 + 全称化"的成本问题。

## 2. 对本轮核心问题的回答

> "当我们已经能够用普通形式化方法验证 Agent 的非干扰性时，究竟有什么必须隐藏、又必须让外部验证者相信的东西，以至于值得引入零知识证明？"

**回答**（`ZK_VALUE_ANALYSIS.md` §8）：

1. 可隐藏的：模型转移结构、秘密输入、内部信息流、证书结构（`ZK_VALUE_ANALYSIS.md` §2）。
2. 必须公开的：命题框架 `Λ,T,|X_L|,|X_H|`、电路模板、模型承诺 `C_M`（§1）。
3. 可验证的：对某个被承诺模型 `M` 的 `C_T(M)`；但**不是**"真实 Agent 满足 NI"——后者是模型来源信任，ZK 无解（§4）。
4. **不可替代的 ZK 增益仅当**"隐藏 + 外部验证 + 无可信方 + 硬需求 + 成本可接受"同时成立；当前至少三项不成立或未建立（§7）。
5. 模型可公开时普通算法/Lean 更便宜；模型需隐藏但有可信方时签名足够（§6）。
6. **"模型可以隐藏" ≠ "值得使用 ZK"**——这是本轮最重要的结论。

## 3. 三个证书都指向 STOP 的理由

1. **内核标准**：互模拟、DFA 等价、集合相等都是教科书结论；本轮未发现新可证性质。
2. **完备性提升不带来 ZK 增益**：自动机/语言证书完备，但完备性来自子集构造与显式表示，在 SNARK 中表现为更多约束，而非更短证书。
3. **三种成本分项都高**：
   - 生成：子集构造最坏指数 / 语言枚举 `O(|Λ̂|^{T+1})` / 关系构造 `O(|S|²T)`；
   - 普通验证：多项式（公开场景足够，无需 ZK）；
   - SNARK 电路：需承诺绑定 + 查找论证 + `|X_H|²` 全称化，成本随证书规模增长。
4. **真实性边界**：所有证书只证明"被承诺模型满足 `C_T`"，不解决模型是否忠实真实 Agent；这一缺口与 Phase 1C 停止条件 5 同构，未被本轮填补。
5. **相关工作已覆盖**：DFA 等价、最小化、互模拟判定、BMC 提供完整公开验证方案；ZK 侧已有隐藏图谓词的存在性证明（Distributed Sentinel §4.8.1），但命题形态不同（存在性 vs 全称等价），不是创新空白（`RELATED_WORK_AUDIT.md` §6）。

## 4.1 Phase 1D.2.1 — Bounded Automata Errata（定义修正与冻结声明）

远端核查发现一处**实质定义漏洞**：原 `TRACE_AUTOMATA_CERTIFICATE.md` §1 的观察轨迹 NFA 未把上界 `T` 纳入自动机结构，却声称 `L(A)=L_T`；而 `PROPERTY_REFINEMENT.md` §1 的 `L_T` 已含 `|w|≤T`，故该等号在原定义下不成立。1D.2.1 只做范围内的定义收紧，不重开研究、不改裁决：

| 修正 | 内容 | 落地 |
| --- | --- | --- |
| **E1 分层 NFA** | `Q_T=S×{0,…,T}⊎{q_acc}`；`τ` 边计数不变、`ℓ∈Λ` 边仅 `i<T` 时 `i→i+1`、`⊢t` 仅从 `i≤T` 发出；给出 `L(A_T)=L_T` 的**双向包含证明**（含计数不变量） | `TRACE_AUTOMATA_CERTIFICATE.md` §1 |
| **E2 规模更新** | NFA `O(\|S\|(T+1))`；DFA 确定化上界由 `2^{\|S\|}` 改为 `2^{\|S\|(T+1)}` | `TRACE_AUTOMATA_CERTIFICATE.md` §2/§5；`COMPARISON_MATRIX.md` §1/§2.2 |
| **E3 DFA 电路成本标估算** | 电路中证"不存在到不一致状态的路径"需**可达集上界不变式（闭包）证书**而非仅"路径约束"；成本记为 `[待验证]` 估算 | `TRACE_AUTOMATA_CERTIFICATE.md` §6；`COMPARISON_MATRIX.md` §2.2/§3.1；`ZK_VALUE_ANALYSIS.md` §5 |
| **E4 PSPACE 推论收紧** | NFA 等价 PSPACE-complete **不推出**"无多项式大小可多项式验证正向证书"；若存在则 `PSPACE=NP`，属依赖复杂度类分离假设的推论，非已证下界 | `TRACE_AUTOMATA_CERTIFICATE.md` §3；`COMPARISON_MATRIX.md` §3.1 |

**冻结声明**（`[数学推导]`）：以上修正只使自动机证书的定义与其目标命题 `L_T` 严格对齐，并收紧复杂度与电路成本的表述；**不改变**三证书的内核判定、ZK 价值判断与成本三分结论。因此 **STOP 裁决原样保留**（见 §1、§3）。不启动 Phase 1D.3、不改 Halo2、不新增文献搜索。修正后本支线（Phase 1C → 1D → 1D.1 → 1D.2 → 1D.2.1）**冻结**，不再寻找第四种证书变体。

**STOP 的准确范围**：停止的是"以有限 LTS、弱互模拟、轨迹自动机语言等价为核心的 IFC-ZK 证书对象"路线；不停止 Agent 安全与密码学信任机制本身，也不排除未来出现真实硬隐私需求时重新评估（重开条件见 §6）。特别地，STOP **不是**"已证明所有紧凑且完备的 ZK 证书不存在"，而是"当前三个候选均未建立 ZK 不可替代价值"。

## 6. 重开条件（供未来参考，非本轮立项）

本裁决只在以下条件出现时重新评估（不满足则不再回到此问题）：

1. 出现**硬隐私需求证据**：模型/轨迹泄露造成实质损害且有外部验证义务，且无可信方（闭合 Phase 1C 停止条件 5）；
2. 出现**相对公开验证/签名的不可替代 ZK 性质**，而非仅"换证明系统"；
3. 出现**固定的模型来源锚定机制**（可信硬件、公开可复现采集 + 承诺），使"被承诺模型"可等同于"真实 Agent"；
4. 若有新证书结构，需同时给出：完备性证明、相对 `I_k`/DFA 的可证紧凑性、以及 SNARK 电路成本估算（不是普通算法复杂度）。
