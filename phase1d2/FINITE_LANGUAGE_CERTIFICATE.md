# Phase 1D.2 — C：有限语言等价证书（Finite-language equivalence certificate）

证据标记：`[定义]`、`[数学推导]`、`[标准结论]`、`[待验证]`。

---

## 1. 证书对象：直接以有限观察语言为证明对象

不再经过状态关系或自动机，直接证明：

```
L_T(M, x_L, h₀) = L_T(M, x_L, h₁) ⊆ Λ̂^{≤T+1}          [定义]
```

其中 `L_T(M,x_L,h) = { w·⊢t | ∃π: visibleTrace(π)=w, Term(last(π))=t, |w|≤T }`（见 `PROPERTY_REFINEMENT.md` §1）。

这是**最接近 `C_T` 定义本身**的证书：证明对象就是目标集合，不引入中间关系。代价是必须给出集合的某种表示。

---

## 2. 有限语言的表示方式

### 2.1 Trie（前缀树）（`[定义]` + `[数学推导]`）

把 `L_T` 的每条串 `w·⊢t` 存为根到叶的路径；叶标记为终止类别 `t`。

- 规模：节点数 `≤ 1 + |Λ̂| + … + |Λ̂|^{T+1} = O(|Λ̂|^{T+1})`，叶数 = 轨迹条数。
- 表示精确、无歧义；同构判定即逐节点相等。
- 缺点：不共享后缀，最坏指数。

### 2.2 DAG（前缀共享 / 后缀共享）（`[定义]` + `[数学推导]`）

- **前缀共享**：trie 已共享前缀。
- **后缀共享**：把相同后缀子树合并为同一节点（本质是最小化 DFA 的前缀 DAG 形式）。
- 规模可显著小于 trie；但合并操作等价于自动机最小化的一部分，构造成本上升。
- 在反例中（左 `ab,ac`；右 `ab,ac`），trie 与 DAG 都是同一棵 4 叶结构，直接同构。

### 2.3 最小化自动机（`[标准结论]`）

把有限语言表示为最小 DFA（Hopcroft 最小化 `O(|Σ| n log n)`）或最小 AC 自动机（多模式匹配）。这是最紧凑的规范表示：两个有限语言相等 ⟺ 其最小 DFA 同构。

- 优点：规范、紧凑、同构判定便宜。
- 缺点：构造需先有 DFA（子集构造），最坏指数；最小化在电路中难算术化。

**三种表示的关系**（`[数学推导]`）：trie ⊇ DAG ⊇ 最小 DFA（规模单调不增，构造成本单调不减）。没有"免费的紧凑"——紧凑性来自共享，共享需要计算。

---

## 3. 能否构造局部、可验证的语言等价证书？

### 3.1 局部性分析（`[数学推导]`）

"局部可验证"指：验证者不必重算整个 `L_T`，只检查少量局部约束即可确认相等。三种候选：

1. **逐串枚举证书**：证明者列出 `L₀` 与 `L₁` 的全部串及一条双射，验证者逐串比对。
   - 局部性：差；验证者工作 = 轨迹数 × 串长。
   - 规模：轨迹数最坏 `|Λ̂|^{T+1}`。
2. **最小 DFA 同构证书**：证明者给出最小 DFA `D₀,D₁` 及同构映射。
   - 局部性：中；验证者检查同构映射是双射且保转移（`O(|Q|·|Λ̂|)`）。
   - 但验证者还需相信 `Dᵢ` 确实等于 `L_T(M,x_L,hᵢ)`——这一步无法局部化，需要另一个证书（回到自动机证书）。
3. **哈希/默克尔承诺证书**：对规范表示（最小 DFA）做承诺，验证者比较承诺值。
   - 局部性：验证便宜（`O(1)` 承诺比较）。
   - 但 soundness 依赖承诺绑定 + 证明者诚实构造规范表示；若证明者可伪造表示，承诺相等无意义。

**结论**（`[数学推导]`）：真正"局部且 sound"的语言等价证书**绕不开**"表示忠实于 `L_T`"这一环——而这正是自动机证书要解决的问题。有限语言证书若只比较表示，就把负担转移到了表示的来源；若验证表示来源，就退化为自动机证书。**没有脱离表示来源的免费局部性。**

### 3.2 能否避免显式枚举全部轨迹？（`[数学推导]`）

- 若 `L_T` 有**简洁表示**（小 DFA / 小 DAG），可以避免枚举：用自动机结构间接表示集合。
- 若语言本身复杂（状态数接近 `|S|`、分支多），任何表示都接近轨迹数 / 子集数 ⇒ 无法避免指数级工作。
- **不写普遍下界**：这是"表示复杂度依赖语言结构"的事实，不是"语言证书必然指数"的定理。

---

## 4. 有界深度 T 对证书规模的影响（`[数学推导]`）

- `T` 是**可观察动作数上界**（不是 Phase 1B 的 cap=50 图节点数）。
- Trie 叶数 `≤ |Λ̂|^{T+1}`：`T` 每增 1，最坏乘 `|Λ̂|`。
- DAG / 最小 DFA 可大幅压缩，但压缩率依赖语言的循环/共享结构；最坏仍指数。
- 好处：`T` 有界使问题**可判定且有限**，可以在固定 `T` 下给出确定规模的证书；这与无界 NI（不可判定）形成对比。
- 坏处：`T` 稍大即规模爆炸；与 Phase 1D 的 `I_k` 索引规模 `O(|S|²T)` 相比，语言证书对 `T` 更敏感（指数 vs 线性）。

---

## 5. 如何扩展到所有允许的高输入对（`[数学推导]`）

`C_T` 要求 `∀x_L∀h₀∀h₁`。语言证书的扩展路径：

1. **逐对比较**：对每对 `(h₀,h₁)` 给出 `L(h₀)=L(h₁)` 的证书。规模 `O(|X_H|²)` 份子证书。
2. **对每个 h 给规范表示 + 全局比较**：为每个 `h` 给最小 DFA `D_h`，验证所有 `D_h` 同构。规模 `O(|X_H|)` 份表示 + 一次同构比较。
3. **参数化表示**：若 `L_T(M,x_L,h)` 随 `h` 有简洁参数化（如 `h` 只影响某个有限域上的标签），可给一个参数化证书覆盖所有 `h`——但这要求模型结构特殊，非一般保证（`[待验证]`）。

**关键**（`[数学推导]`）：即使语言证书对**单对**完备，扩展到 `∀h₀,h₁` 仍需 `|X_H|` 或 `|X_H|²` 量级的表示。这与 `I_k` 证书的 (INIT) 全称条件面临同样的量词成本——语言等价 certificate **不自动解决全称化**。

---

## 6. 可扩展性的诚实边界（`[数学推导]`）

**不能**因为"有限语言可以显式枚举"就默认这种方法实际可扩展：

- 有限 ⇒ 可枚举 是**可判定性**陈述，不是**可行性**陈述；
- 枚举规模 `|Λ̂|^{T+1}` 随 `T` 指数，且需对每个 `h` 重复；
- 紧凑表示（最小 DFA）的构造本身是 PSPACE-hard 问题的实例（NFA→DFA 最坏指数）；
- 在 SNARK 电路中，"列出集合并逐项比较"意味着 `O(轨迹数)` 个约束，不会比普通算法更便宜，反而增加证明生成成本。

---

## 7. 隐藏模型与 ZK 接口（`[待验证]`）

- 若语言表示（trie/DFA）作为见证提交并隐藏，验证者只见承诺与"相等"的验证结果。
- 但验证者无法确认被承诺的表示忠实于 `C_M` 中的模型——表示来源信任问题延续（见 `ZK_VALUE_ANALYSIS.md`）。
- 若表示公开，普通同构检查即可，ZK 无增益。

---

## 8. 小结

1. 有限语言证书直接以 `L_T` 为对象，是三种证书中最贴近 `C_T` 定义的一种。
2. 表示方式 trie / DAG / 最小 DFA 在"规模 vs 构造成本"上权衡；紧凑性来自共享，非免费。
3. 局部可验证性绕不开"表示忠实于 `L_T`"这一环；若验证该环就退化为自动机证书。
4. `T` 有界使问题可判定，但规模对 `T` 指数敏感（比 `I_k` 的线性 `T` 更差）。
5. 扩展到 `∀h₀,h₁` 仍需 `|X_H|` / `|X_H|²` 表示，不自动解决全称化。
6. **不因有限可枚举就默认可扩展**；ZK 增益依赖"必须隐藏表示且外部必须验证"的硬需求，该需求未建立。
